# Codex 本地插件

在能力中心选择 Codex 桌面或 CLI，点击「连接原生引擎」。仅连接用户选择的目标，不自动用 CLI 替代桌面引擎；不自动安装或更新 Codex。

「发现」包含代码审查、OpenAI 官方公开文档两个自有 MIT 插件；也可以「导入插件」选择已有本地插件目录。目录需含原生 `.codex-plugin/plugin.json` 或 portable `plugin.json`，并声明 name 与 version。当前不直接下载第三方仓库或归档，也不接管官方已安装插件。

检查安装会列出文件数量、许可、Skills、MCP连接域名/程序与脚本/钩子风险。只有确认后才写入目标的插件来源、缓存和配置。插件可能运行程序、读取文件或发送数据，需先审查来源；未知许可证不能理解为已取得使用权。外部服务的OAuth仍需在Codex授权，不由元衡账号代替。

「本机管理」支持启用、停用、检测加载、卸载和重新安装。「检测加载」仅验证短生命周期的原生app-server发现的Skills及声明的MCP；不运行模型、不执行插件工具、不验证外部服务授权，也不代表当前已打开的GUI聊天已经重载。安装/启停后在Codex新建聊天。CLI和桌面若使用同一个Codex目录，会共享插件状态，而非按元衡平台账号隔离。

插件身份由内容摘要和原生市场名确定，同名不同内容会作为独立版本，不自动替换旧版本。安装新版本前应先停用旧版本；本版没有自动升级或跨版本迁移。卸载由Codex删除缓存与安装配置，保留本机来源快照用于重装；不终止现有聊天、不撤销外部服务授权、不删除其他Skills/MCP。

安装结果未知时先刷新。刷新能够确认已安装或已卸载的结果；无法确认的记录保留待核对，不能自动重发安装。快照、市场配置或已安装内容被修改时停止相应操作，避免覆盖用户修改；请到Codex核对后再恢复。原生接口不支持时明确报错，不绕过权限或写伪造缓存。

管理数据在所选Codex目录的`yuanheng-native-plugins`中，不包含登录令牌，不进入元衡数据库同步。安装前的内容扫描是风险提示与文件边界保护，不能证明代码无恶意，也不是沙箱。代码执行遵循Codex自身权限。

已隔离验证macOS ARM64上的CLI 0.167.0与桌面内置引擎0.166.0-alpha.5.1。Windows/Intel及真实OAuth未完成运行验收；找不到对应原生可执行文件时会报错。没有声称第三方API模式支持所有云连接器。
