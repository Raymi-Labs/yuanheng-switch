# DSH 首次使用

在元衡登录后，在工作台选择 **DSH → 安装与配置** 即可直接开始安装，无需跳到工具管理。也可以在工具管理选好模型和令牌分组后点击 **DSH → 一键安装**。安装期间会显示进度条、当前阶段、已用时间和最近进展，并提供取消按钮。下载时显示已收到的大小；能获取总大小时显示下载百分比。校验、解压、安装包和验证阶段分别显示状态，不把等待时间换算成百分比。超过一分钟没有新进展会提醒检查网络或系统提示，并不代表安装已经失败。

元衡会下载独立的运行环境和 DSH，检查能否运行，自动选择这份安装，然后应用配置并打开本机 Web 界面。旧的自选目录不会被删除；安装期间若你重新选择了路径，元衡会保留新选择并提示重新检测。首次进入 DSH 时，阅读它的预览版说明并点击继续，即可创建会话。DSH 目前使用浏览器界面；请保留启动时打开的终端，关闭该终端可能结束 DSH 服务。

- **获取官方最新版**：每次安装从官方 npm 的 `latest` 标签读取版本后安装。它由 DSH 官方维护，可能仍是预览版，不会固定在旧版，也不会自行选择 `next` 等其他通道。
- **更新 DSH**：在工具管理中查看元衡安装的 DSH 当前版与官方版；发现新版后点击“更新 DSH”即可。工作台仅在安装或更新期间显示进度与取消按钮。支持检查更新、取消、失败重试，失败或取消时保留原安装；检查失败不会显示“无需更新”。更新完成后重新打开 DSH 使用新版，运行中的任务不会被自动终止，会话和配置继续保留。
- **已有 DSH**：可以复用已安装的命令行，或通过“选择路径”选择应用/源码目录。源码需要先有依赖和 Web 构建；不完整的源码可以保留，清除自选路径后改用元衡一键安装。自选路径及外部安装请通过原渠道更新。
- **安装失败**：提示会区分运行环境下载、校验、解压、npm 安装和运行检查。检查网络与磁盘后重试即可，不要删除会话目录或关闭系统安全检查。
- **安装成功但配置失败**：安装保留，请核对模型、分组与配置提示，再点击配置或启动。仅显示安装成功不代表已经获得模型权限。
- **取消安装**：元衡停止本次安装任务，保留原有安装。安装期间退出页面或切换账号，不会在完成后继续执行旧账号的自动配置/启动。
- **不能回复**：先核对 DSH 中的当前模型与元衡所选分组，再记录错误内容；界面可打开不代表上游账号、额度和网络都正常。

元衡托管的 Claude 请求允许等待下一条模型输出事件最多 **10 分钟**，失败后最多自动重试 **1 次**。这是流空闲等待，不是整个任务的时长上限；正常持续输出的长任务可以继续。用户仍可随时停止请求，GPT 和自有供应商的等待策略保持原样。

已有用户更新元衡客户端后，如果 DSH 显示需要更新配置，请重新点击配置或启动，然后刷新或重启 DSH。可信旧配置可以复用原令牌；如果提示配置被外部修改，请先核对，不要删除会话或强行覆盖。自定义 profile、远程 Web 和手工添加的供应商不会自动迁移；旧会话若使用手工供应商，需要在 DSH 中切换到元衡托管的 Claude 路由，手工设置的覆盖仍以用户选择为准。已经发出的请求不会追加等待时间。上游或代理的更短时限仍可能先触发；等待本身不按秒计费，但模型继续处理和重复请求可能消耗额度。

一键安装只写元衡管理的工具目录，不覆盖旧源码、系统 Node.js 或历史会话；配置继续使用原有 DSH 配置的拥有权保护。本机 Web 绑定 `127.0.0.1` 并由 DSH 生成访问地址，不开放给局域网。元衡启动此 Web 时关闭 DSH 会话遥测；发送给模型的正文仍会经所选元衡渠道处理。

开发验证覆盖隔离目录中的官方 npm 安装、Web 页面、模型目录和本机模拟上游回复，不使用真实用户令牌。Windows 真机安装、系统代理环境及真实上游模型调用需分别验收。

### 启动时提示“DSH 配置已变化”

v0.1.99 修复了 DSH 自身迁移凭据格式、保存欢迎页或切换目录内模型后被误判的问题。升级元衡客户端后重新点击启动即可识别原配置，无需重装 DSH 或删除会话。如果接口地址、凭据值、供应商配置或目录外模型确实发生变化，保护仍会阻止自动覆盖，请先核对修改内容。重新配置与恢复会保留其他凭据、浏览器会话记录和非托管偏好。
