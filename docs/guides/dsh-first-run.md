# DSH 首次使用

在元衡登录后，在工作台选择 **DSH → 官方下载**，或在工具管理中点击 DSH 的 **官方下载**。元衡引导安装 DeepSeek 官方独立桌面应用：

- **Windows**：打开 [官方 64 位安装包](https://download.deepseek.com/desktop/dsh-latest-windows-x64.exe)，下载后运行安装程序。
- **Mac**：弹出版本选择，Apple 芯片（M 系列）选择 Apple 芯片版，Intel 处理器选择 Intel 版；可在苹果菜单 → 关于本机确认。打开下载的 DMG，将 DSH 拖入“应用程序”。取消选择不会下载或修改配置。
- **其他系统**：目前没有接入官方桌面安装包，不自动改装 Web 版。官方入口为 [DeepSeek Harness](https://www.deepseek.com/harness/)。

安装期间元衡显示等待状态，每三秒检测一次，最多等待五分钟；浏览器下载进度以浏览器为准。检测到桌面应用后，当前账号和页面仍未变化时，元衡预检并应用模型配置，成功后启动 DSH 桌面端。配置失败会保留安装结果，请核对提示后重试。超过五分钟可点击重新检测，或选择实际应用路径；打开下载链接不代表安装成功。

- **已有 DSH 桌面端**：自动检测系统安装位置；也可选择应用路径。Windows 选择包含 `DeepSeek Harness.exe` 的目录，Mac 选择 `DeepSeek Harness.app`。已明确选择的源码仍从其 Desktop 入口启动；仅含 CLI/Web 的源码不会被默认启动为网页。
- **更新 DSH**：在 DSH 桌面端菜单中检查更新。元衡不把 npm 的版本号当作桌面端更新版本，也不替换用户的桌面安装。
- **旧 Web 安装**：保留元衡原有的运行时、配置和会话。它不再计入桌面端已安装，也不抢占默认启动；仍需本机 Web 时，可主动使用工具管理中的“启动 DSH Web”。该入口需要已有 Web 运行时、CLI 或完成构建的源码；请保留其启动终端，关闭终端可能结束 Web 服务。
- **不能回复**：先核对 DSH 中的当前模型与元衡所选分组，再记录错误内容；应用可打开不代表上游账号、额度和网络都正常。

## Claude 请求策略

已有用户更新元衡客户端后，如果 DSH 显示需要更新配置，请重新点击配置或启动，然后刷新或重启 DSH。可信旧配置可以复用原令牌；如果提示配置被外部修改，请先核对，不要删除会话或强行覆盖。自定义 profile、远程 Web 和手工添加的供应商不会自动迁移；旧会话若使用手工供应商，需要在 DSH 中切换到元衡托管的 Claude 路由，手工设置的覆盖仍以用户选择为准。已经发出的请求不会追加等待时间。上游或代理的更短时限仍可能先触发；等待本身不按秒计费，但模型继续处理和重复请求可能消耗额度。

官方安装器负责桌面应用安装；元衡不删除旧源码、旧 Web 运行时或历史会话，配置继续使用原有 DSH 配置的拥有权保护。本机 Web 绑定 `127.0.0.1` 并由 DSH 生成访问地址，不开放给局域网。元衡启动此 Web 时关闭 DSH 会话遥测；发送给模型的正文仍会经所选元衡渠道处理。

桌面流程测试覆盖 Windows 下载、Mac 两种芯片选择、取消、安装后配置/启动和失败保护；安装及模型请求通过模拟验收，不使用真实用户令牌。旧 Web 的隔离目录验收记录保留。Windows 真机安装、桌面真实上游模型调用需分别验收。

### 启动时提示“DSH 配置已变化”

v0.1.99 修复了 DSH 自身迁移凭据格式、保存欢迎页或切换目录内模型后被误判的问题。升级元衡客户端后重新点击启动即可识别原配置，无需重装 DSH 或删除会话。如果接口地址、凭据值、供应商配置或目录外模型确实发生变化，保护仍会阻止自动覆盖，请先核对修改内容。重新配置与恢复会保留其他凭据、浏览器会话记录和非托管偏好。
