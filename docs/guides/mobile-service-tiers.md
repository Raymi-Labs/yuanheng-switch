# 手机客户端速度档位

单模型聊天参数区提供标准、Fast、UltraFast。只有当前账号、模型与分组的能力接口实际返回的选项才可选择；服务端未部署或查询失败时仍可用标准，付费选项不开启。详情通过信息按钮查看，倍率不是速度保证。

标准不发送service_tier，Fast发送priority，UltraFast发送ultrafast。倍率按接口返回的当前2/6约定校验；客户端不修改Token或结算金额。字段与思考强度独立。服务端接口为`GET /api/user/service-tiers?model=...&group=...`，原生白名单复用账号会话鉴权和发起userId，不含上游Key或渠道ID。

选择只保存到当前账号的当前对话，刷新恢复后重新校验；新对话标准，旧对话缺字段标准。模型/分组变化不会静默改付费档，不支持时阻止发送并提示重新选择。生成中选项锁定。失败后可明确点击“按原参数重试”，使用原消息、模型、分组和档位快照重新校验，不自动重发。回复旁只显示“本次选择”，不据上游default回显宣称加速生效。

本次仅更新mobile单模型聊天。桌面工作台是外部Agent配置，不提供按对话付费速度全局开关；多模型比较、iOS商店发布不在本次范围。网页服务端能力与计费需先部署，1657关闭时用户不会因此获得加速选项。APK发布不等于生产加速已启用。
