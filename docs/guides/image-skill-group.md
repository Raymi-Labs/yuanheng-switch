# 内置图片 Skill 的调用分组

能力中心的图片分组控制内置图片 Skill 的模型目录及生成/编辑请求。用户显式安装、启用或更新连接时，沿用已选图片组；没有选择时默认“生图和视频”。主组无权限或已删除时手动选择其他有权限的图片组，不回退到聊天凭据。

默认组支持有权限的“福利”组补充：同一个模型两边都有时使用“生图和视频”；只有主组目录成功确认没有该模型，才检查福利组并使用该模型。两边都没有就提示不可用。目录读取失败、认证失败、额度不足、超时或生成失败均不跨组重发。按实际使用的组计费，可在现有图片分组旁的信息图标查看规则。用户主动选其他组时保持单组。

同账号、同图片组复用一枚客户端管理的图片专用令牌。默认组和福利组各使用自己的单组令牌，在提交前选择其中一枚；每枚令牌都关闭平台跨组回退。配置时验证令牌真实分组、单组路由及可用性；聊天统一令牌、聊天配置和平台自动路由保持原行为。图片令牌停用、额度不足、删除、组被修改或同名重复时，提示到平台核对，不覆盖规则或另建令牌绕过限制。不同工具可共用同图片组凭据，也可各自选择不同组。

已保存的旧图片连接仍显示原选择，但旧记录不作为专用组凭据使用。点击“更新图片连接”或更新 Skill 后完成验证；未更新时不发送托管图片请求。自动安装 Skill 只安装脚本，不因配置聊天工具就创建图片令牌。明确使用外部 API Key 的脚本调用仍由用户自行配置，不能认为已受到客户端分组约束。

模型目录和图片生成使用同一个工具绑定的 `/imagegen/<tool>/v1` 连接。默认连接的目录合并主组和福利组模型，沿用版本及质量排序；自动选择与显式型号都由 Core 按精确模型ID选组。JSON与multipart的原始媒体内容不重写，生成仅提交一次。Codex CLI/桌面仍分别绑定；本次不修改 Codex 原生图片接口或官方 OAuth 行为。聊天多Agent串组的整体方案已经撤回，没有改写服务端选路或鉴权协议。

当前客户端内置脚本只支持图片生成与编辑。名称中的“生图和视频”是默认分组名称，不代表这个脚本已经支持视频接口；客户端图片/视频创作页和用户另行安装的脚本不在本轮改动范围。

已完成合成HTTP凭据、Core隔离、脚本及页面测试。未修改真实令牌或发起收费生成，没有签名安装包/手机/Windows真机验收。配置时验证不能保证用户以后在平台手工改令牌仍保持原范围，修改后须重新校验。多个设备同时首次创建仍无服务端幂等保证，发现同名重复会停止。
