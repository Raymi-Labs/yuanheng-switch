# Accio 兼容检查与问题定位

工作台和工具管理会显示已安装的Accio版本及元衡已验证版本。当前版本未验证或安装路径无法确认时，先重新检测或选择官方应用路径；若确为新版，到“设置 → 关于”检查元衡更新。不要删除版本限制或替换官方签名。

官方版本查询在后台独立运行，不阻塞其他工具检测。成功结果缓存6小时，失败缓存5分钟；失败时旧结果会标为过期，不代表官方仍是那个版本。官方有新版也不会影响你使用当前已验证的旧版。网络请求仅访问公开更新元数据，不携带元衡令牌、Accio账号、电脑名称或本地文件路径。

模型回复不等于文件工具执行成功。任务等待时先看Accio内是否需要逐次批准文件操作；只批准确认的操作。工具参数错误保留提示及诊断编号，限流/额度错误先核对元衡控制台，网络失败先检查出站代理。原任务没有明确停止前不要连续重复发送。官方电商云端工具执行尚未接入，重装或重试不会自动增加这项能力。

维护者可运行 `python3 scripts/check-accio-release.py` 只读核对官方版本。返回0表示官方版本在源码验证列表，1表示需要兼容审查，2表示查询失败或元数据无效。离线测试为 `python3 scripts/test_check_accio_release.py`。仓库工作流每6小时运行并支持手动触发，只有合入默认分支后才会实际定时执行；通知由GitHub个人Actions通知设置决定。

发现新版后仍需校验官方签名、检查固定摘要的协议回归，再进行受控启动、模型及文件操作验收。监控不会下载、执行、自动改版本门禁、创建Issue或调用付费模型。Windows Accio启动未实现、Intel需单独真机验证。

Accio 0.37.1在Apple Silicon专用QA机已验证原生停止：任务未完成时点击停止，官方记录aborted、Core活跃连接归零，同一对话随后可以继续回复。这不能保证上游已生成内容不计费。原生模型菜单已验证选择并切回，跨不同模型的实际推理、重启后保持仍需独立验收；没有拿UI选中标记替代实际请求日志。
