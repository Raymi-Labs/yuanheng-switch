# Accio 兼容检查（维护者）

用户配置和启动不受实测版本列表限制。本检查提供排查证据，不修改产品版本策略，也不自动更新用户应用。

用户遇到实际故障时：任务等待先检查Accio内是否正在请求文件操作审批；工具参数错误保留错误提示与诊断编号；限流/额度错误核对平台用量；网络失败检查出站代理。原任务没有明确停止前不要连续重复发送。官方电商云端工具尚未接入，不因版本允许启动而自动具备。

## 一条命令

在已安装项目 Node 依赖的 macOS 机器执行：

```sh
python3 scripts/check-accio-package.py --expected-version 0.37.2
```

省略版本参数会检查官方更新源当前的 ARM64 包。脚本只访问固定官方域名，校验下载大小/SHA512、归档路径、Bundle ID/开发者签名及包内版本，再提取协议模块执行合成目录、模型、工具、SSE和取消测试。不会启动官方应用、读取本机登录账号或发出付费模型请求；官方服务器会看到下载请求的出口IP。临时包和测试进程在结束时清理。

仓库 `Accio Compatibility Diagnostics` 工作流在相关PR上自动跑离线防回归测试；手动运行工作流可完成官方包检查，无需维护者本机操作。工作流未合并部署前不代表远端已运行。本轮没有恢复客户端自动查询或周期性任务。

## 结果含义

| status | 含义 | 用户入口 |
| --- | --- | --- |
| `protocol_passed` | 官方包身份通过，已选协议声明结构/依赖匹配，16项离线行为检查通过 | 不受影响 |
| `review_required` | 官方版本已变化、关键声明有变化或歧义、或执行环境不能验证macOS签名 | 不受影响，维护者复核 |
| `check_failed` | 下载、摘要、签名、归档、运行超时或协议回归失败 | 不受影响，保留真实诊断 |

`protocol_passed` **不代表原生GUI、官方登录、店铺/采购云端工具或真实模型任务已验收**。脚本报告明确保留 `nativeGuiTested:false` 和付费请求数0。

## 后续版本如何复用

基线由已审阅的0.37.1官方worker生成，仓库只保存声明的语法指纹、标识符映射和依赖索引，不提交厂商代码。自动匹配允许位置/空白及一致的变量重命名，保留属性名、字符串、操作符、控制流、声明依赖和SDK模块次序；同形节点必须由依赖和模块次序唯一定位。匹配不唯一、缺失或变化时不执行候选声明。

仅选定声明接受检查；未提取的应用代码及用合成桩代替的登录、磁盘缓存、遥测行为不属于结论。若关键声明变化，维护者审查差异并补充测试，不能为让检查变绿直接更新摘要或期望值。旧的按摘要锁定的检查仍可复查0.35.2/0.35.3/0.37.1。
