# 图片与视频

登录元衡后，点击左侧「声音克隆」下面的「图片与视频」。不需要另外安装 Agent 或粘贴 API Key。

1. 选择「图片生成」或「视频生成」，再选择模型。页面固定使用“生图和视频”分组；缺少权限时联系平台开通，不会自动使用聊天分组。
2. 填写画面描述。模型支持参考图时可上传PNG/JPEG，Muse另支持WebP和最多4张，单张不超过10MB。
3. 可在「更多设置」调整尺寸或比例、视频时长。界面仅提供所选模型已适配的参数。
4. 点击「生成」。此操作按模型与分组计费，具体费用以平台用量记录为准；本版不提供精确估价。
5. 完成后，在下方「本机作品记录」点击「预览」或「保存」。作品存在本机，保存可另选目录。

要让生成的图片动起来：在已完成图片旁点击「用作视频参考图」，页面会选择当前分组可用的图生视频型号（当前主要为Muse），带入图片。填写“镜头怎么移动、主体做什么”的描述，确认模型和时长后再点击生成。准备草稿本身不会提交视频，也不会产生新的生成费用；下载原成品仍会访问图片服务。没有授权的图生视频型号时，按钮不可用。

PNG、JPEG和WebP作品会在本机转换为PNG，长边超过1536像素时等比例缩小，不裁剪，不覆盖原作品。上传参考图单张最多10MB，边长最多8192像素、总像素最多16,777,216；损坏文件在提交前拒绝。Muse接受PNG/JPEG/WebP，其他支持参考图的型号仍为PNG/JPEG。切换兼容型号保留参考图；从Muse切换到单图模型仅保留首图并提示，切到不接受参考图的型号会清除全部图片。

Muse按用户提供的20261028上游文档适配4–180秒整数、默认4秒、720p两方向、最多4000个Unicode字符。最多4张参考图，单张10MB、总计24MB；可以逐次添加、删除、点“前移”调整顺序。第一张是首帧，其余是人物、场景或画风参考，最后一张不是尾帧。单图使用input_reference，多图仅发送images数组，不混发。超过30秒按段生成并拼接，应按段描述镜头，不能理解为一个连续长镜头。新能力的真实生成验收由另一个会话执行，当前适配不宣称已完成线上验证。

本版能力边界：Muse开放文生/图生视频；Grok两款、Snow Grok、Omni720p和Omni1080p仅开放文生视频。Veo已从客户端支持范围移除，不显示在可选模型中，也不接受新生成提交；不删除旧作品记录，不修改平台渠道。Omni720p按用户确认恢复，型号flow-video-gemini-omni-flash-1.1，4秒、720p横屏或竖屏，提交等待600秒。

Muse首次提交最长等待1800秒（30分钟），其他视频仍600秒（10分钟），允许供应商较晚返回任务编号；查询单次最多20秒。取得编号后可以离开页面，返回后点击原记录的「继续查询」。自动查询每15秒一次，Muse最多120次（约30分钟，加上查询耗时），其他型号最多40次，然后暂停；失败也会暂停并保留原任务。查询不会重新提交生成。暂停等待或关闭客户端不等于上游任务取消，也不意味着退款。上游或网络自身可能提前断开，延长客户端等待不是成功保证。

提交超时、连接断开且没有任务编号时，记录会提示结果未知。先到平台查看用量和任务情况，不要连续点击生成。下载失败可以重试下载原成品，不需要重新生成。

历史最多 50 条，仅保留模型、时间、任务编号等必要信息，不保存描述和参考图。不同账号的记录隔离。删除本机记录会删除对应本机成品，无法恢复；已另存的副本不受影响。未完成视频保留记录供继续查询。

当前适配 GPT Image（包括 Sunburst、Flare）、Grok 图片和 Gemini 原生图片，以及 Grok、Muse、Omni 720p／1080p、Snow Grok 视频型号；实际可选列表以本版适配和分组授权交集为准。Grok 视频首版只支持文生，使用480p；Muse默认4秒、720p，最终时长可能被供应商调整。图片成品上限64MB。视频通过平台MP4内容接口流式下载到磁盘，最长等待15分钟、单文件上限256MB，失败清理临时文件，可重新下载同一结果；不发送HEAD或Range请求。超过64MB的视频不通过页面内嵌预览，请点保存后用播放器打开。

图片既可接收内嵌数据，也可接收受信任图片服务的HTTPS链接。链接按账号保存在系统凭据库，不显示在历史中；点击预览或保存时获取原图，失败可重试下载。下载不携带元衡账号凭据、提示词或参考图，不自动跟随跳转；未知域名、非公网目标或不支持的文件会被拒绝。它沿用客户端网络代理设置，图片服务可看到正常网络出口IP。删除作品会清理其保存的下载地址。

本地模拟接口、前端回归和原生检查不等于生产模型生成成功；发布前仍需按实际账号确认权限及必要的真实生成结果。
