TRAE 是辅助配置：用户在官方设置中保存模型，然后在原生模型菜单选择。它不承诺静默导入配置。停止观察证明本地任务结束，不证明上游停止计费。国际版 3.6.4 旧本地代理路径曾有取消失败，不能套用国内版 Responses 的验收结论。

Accio 的商品任务是本地文件工作流，不代表搜索供应商、连接店铺、采购、支付或发布已经接入。官方最新元数据已出现 **0.37.2**，尚未验证，本次不放宽门禁；已允许版本为 0.34.5 / 0.35.3 / 0.37.1，其中本文商品工作流证据只对应 0.37.1。此前偶发的未知上游事件已有诊断补强，但数次成功不能证明所有根因都已消除。

## 可复查证据

- 商品任务使用合成资料与 Astra / 鹈鹕王，共 19 条 HTTP 200 且有正输出的模型记录。JSON 对象比较和 Markdown 完整比较确认修订仅改变指定标题；源资料与保护文件未变。
- 应用重开时改选另一菜单模型但未发送请求，证明选择保留；随后恢复 Astra。它不证明另一模型实际推理通过。
- 补充的客体 macOS 冷启动不产生新模型请求。使用已验证 Core `95671f5a81321c717aabb6c9552e1edd79af20664fe98c0275756823ee2c50f1` 受控启动，不能冒充最新 GUI 安装包整体回归。
- 离线检查器的 3 项测试涵盖价格变动、重复 SKU、缺失事实、虚假发布状态、预览不一致与错误语言字段。检查器只核对合成样例结构与部分事实，始终要求人工审稿，不保证营销质量或平台合规。
