# Meta API 手机客户端 v0.1.0-alpha.3

- Android 和 iOS 应用显示名称统一为 Meta API，更新登录页、导航、关于与系统权限提示。
- 官网、充值、隐私政策及邀请入口使用 meta-api.com；账号与模型接口沿用已有兼容地址。
- Android 保留原包名和正式签名，versionCode 递增为 3，可覆盖旧测试版并保留本机数据。
- iOS 显示名已同步；开发归档不代表 TestFlight 或 App Store 上架。

Android APK 支持 Android 10+、ARM64。iOS device unsigned 归档不能直接安装；simulator adhoc 归档仅供模拟器使用。
