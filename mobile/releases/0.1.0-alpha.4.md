# Meta API 安卓客户端 v0.1.0-alpha.4

- 新增声音克隆：上传已授权的声音样本，选择分组并输入文字生成语音，支持试听和停止等待。
- 生图支持最多4张参考图、画笔遮罩与收藏参数复用，具体效果取决于模型支持。
- 模型广场返回前台自动刷新，调整滑动切页与小屏媒体布局。
- 修复音频播放被安装包安全策略拦截、替换样本误用旧音频及遮罩触控问题。
- 保留账号隔离、兑换防重复与正式签名；Android versionCode=4，可覆盖更新官方旧测试版。

支持 Android 10+、ARM64。本次仍属公开测试版；真实音频/多图模型调用、相册授权和安卓真机触摸尚未完成验收。生成按平台用量计费，停止等待不保证服务端取消或退款。

仅发布安卓 APK 与 SHA256 校验文件，不发布 iOS 安装包，也不更新桌面客户端。
