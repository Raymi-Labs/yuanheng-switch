# Meta API 安卓客户端 v0.1.0-alpha.6

- 修复模型广场因目录数据较大而提示“响应数据过大”的问题。
- 模型卡片分批显示，支持加载更多；搜索与筛选仍覆盖完整目录。
- 保留模型价格、分组和详情，异常响应明确提示，不显示不完整目录。

支持 Android 10+、ARM64，沿用原正式包名和签名，versionCode=6。官方旧版可覆盖升级；第三方重新签名的测试包不保证能覆盖安装，请勿为安装而盲目卸载已有数据。

本次为安卓公开测试版。已完成合成目录、原生读取边界和320/390窄屏浏览器检查，尚未完成本版本Android真机验收。不发布iOS安装包，不更新桌面客户端。
