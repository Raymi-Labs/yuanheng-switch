# Meta API 安卓客户端 v0.1.0-alpha.5

- 单模型聊天新增速度选择：标准、Fast、UltraFast；可用选项和倍率由当前账号、模型、分组的服务端能力决定。
- 档位按对话保存，新对话默认标准；恢复、切换分组后重新验证，不自动升档或降档。
- 失败请求可按原消息、模型、分组和档位手动重试，发送前再次校验，不自动重发。
- 保留原正式安卓签名和包名，versionCode=5。

服务端能力与计费尚未开放时仅可使用标准档。×2/×6为费用倍率，不是速度保证；取消或超时不保证服务端免扣费。本次未调用真实加速模型，真实扣费和安卓真机验收未完成。

Android 10+、ARM64公开测试版；不更新桌面客户端，不发布iOS安装包。
