# Agent Note: 安卓测试 APK 官网分发

Status: implemented

## Problem

Android 0.1.0-alpha.1 已完成构建、固定密钥签名并公开发布，但官网尚无手机入口。用户明确先在元衡官网提供 APK 下载，iPhone 签名继续暂停。

## Decision

复用现有下载桶、域名及不可变对象上传函数，独立手动工作流只同步已发布移动版本的 APK 和校验文件到 `mobile/releases/<version>/`。先核对提交的版本元数据、GitHub 资产摘要、APK 签名证书和校验文件，再写对象，最后从公开域名下载完整文件核对摘要。官网仓库独立增加测试版入口，桌面 latest 不变。

检索现行笔记：移动客户端架构与 R2 桌面分发部分重叠，互链保留；新篇拥有移动文件分发，不覆盖桌面清单/镜像决定。APK 不重打包、不改版本；流程变化不伪造新客户端版本。现有公开测试版 Release 保持原文件。

## Alternatives considered

- 仅放 GitHub 链接最简单，但已有官方下载域名可改善访问，并保留 GitHub 备用。
- 把 APK 加入桌面稳定版清单会混淆版本、平台及更新协议，因此独立版本路径。
- 自动发布所有移动构建会把未经选择的 alpha 暴露给用户，采用已发布版本加固定摘要校验。

## Verification

7 项移动分发回归与 10 项原桌面不可变对象回归通过；笔记结构检查通过。测试覆盖缺资产、重复资产、摘要错误、证书错误、本地字节变化和同版重试。
同版重试沿用既有条件写入和摘要检查，不同内容不可覆盖。
真实 R2 分发、官网上线与公开下载需分别核对工作流和线上结果，离线测试不替代上线。

## Consequences

公开下载不等于 Android 真机业务验收；继续标记 alpha。下载域名故障可使用 GitHub 备用。iOS 未签名 archive 不出现在普通用户下载入口。
