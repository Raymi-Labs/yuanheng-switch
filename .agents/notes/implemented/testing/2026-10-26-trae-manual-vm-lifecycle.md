# Agent Note: TRAE 人工测试窗口退出与超时说明

Status: implemented

## Problem

用户反馈测试环境打开后自行关闭。现有人工.command调用与自动测试相同的run分支，30分钟后直接SIGINT停止VM，10秒后升级SIGTERM，没有预告或续时，也不把退出原因写入持久日志。旧日志仅有Tart输出，不能区分用户关窗、超时和恢复错误。现时复跑官方挂起状态成功，guest及已登录TRAE正常，尚未复现立即关闭；不能将历史VZErrorDomain12直接当作此次原因。

## Decision

人工入口使用独立run-manual：显示60分钟时段，剩5分钟提醒，终端回车可续时；到期或终端关闭请求Tart原生挂起，保存内存/登录状态，不对人工VM强杀。挂起失败明确报错并标记仍运行，由用户/助手处理，不谎报已收尾。自动测试/guest命令继续有界停止，不用人工续时放宽其结束条件。

所有动作记录开始时间、PID、结束时间、运行时长、停止触发原因及退出结果；原始第三方错误保留于本机日志，不上传。人工.command失败后显示中文提示和日志位置并等待回车，避免错误窗口立即消失。人工Tart子进程使用独立进程组但保持监督句柄，防止终端Ctrl-C绕过监督器直接停止VM；父shell捕获INT使子进程保存后仍能显示结果。输出通道关闭不会因EPIPE打断状态保存。原生挂起命令成功后仍等待run子进程退出，未退出明确标记unconfirmed。

实现放在现有专用QA目录的session-supervisor.cjs、qa.cjs和人工.command，不改变客户端产品或Accio工作VM。可复用的虚拟时钟测试存放在该QA目录，原始数据及凭据不提交仓库。

## Alternatives considered

- 只把30分钟改成更长：能延迟中断，但仍无预告、不能区分退出原因，无法解释或稳定人工测试。
- 完全移除定时结束：使用简单，但遗忘窗口会长期占资源，与用户要求不符。
- 人工预告/续时/原生挂起与自动测试有界停止分开：增加少量监督代码，但保留可恢复状态并让退出原因可核对，采用。

## Testing

10项合成监督测试通过：预警/到期保存、回车续时、重复信号、终端EOF、挂起失败重试、挂起返回但runner未退出、异常退出、spawn失败、自动测试有界停止和迟到完成；每个测试结束断言定时器和监听均清零。超时用虚拟时钟推进，无1小时空等。

实际QA VM经过两轮人工入口恢复与Ctrl-C挂起，Tart报告snapshot created successfully，owned run子进程code0；guest核对官方安装、资料目录、专用共享材料仍在。真实PTY按回车生成renewed记录。重复启动返回already running/code2，原VM仍running；修复后.command保留中文错误和按回车关闭提示，用户无需从消失窗口猜测原因。最终Ctrl-C后shell保留成功结果，按回车退出code0；子进程停止及快照保存完成。官方登录画面先前已通过截图核对，本轮不发模型请求。

## Consequences

人工测试不再使用无预告的30分钟停止，用户可以续时且失败信息可核对；代价是维护人工/自动两种监督策略及本机操作日志。Tart/macOS原生挂起仍可能失败，失败会保持窗口并明确提醒；不通过删快照或重建系统隐式恢复。监督不能捕获SIGKILL或宿主掉电；日志不明确时不编造原因。此次用户描述的立即关闭未能复现，旧日志缺少时间/触发原因，仍保留该不确定性。
