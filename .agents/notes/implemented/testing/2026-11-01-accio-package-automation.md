# Agent Note: Accio 官方包兼容检查自动化且不控制用户入口

Status: implemented

## Problem

取消精确版本门禁后，仍需减少官方更新后的重复人工验证。现有协议脚本覆盖目录、工具、流式响应及取消，但依赖固定worker摘要与混淆符号，单纯版本查询无法证明兼容。

## Decision

复用官方固定更新源、签名身份及已有16项离线协议检查（此前历史记录写15项，当前脚本实际输出16项）。自动读取元数据、校验下载大小和SHA512、验证安全归档路径和官方签名、提取worker，生成机器可读结果。与已审阅关键声明结构一致的新版可复用检查；关键实现变化或匹配不唯一时报告待复核，不执行未知代码，也不阻止产品配置启动。

检查仅执行提取的已识别协议声明及合成桩，不启动官方应用，不读取用户账号/聊天/电脑名称，不调用收费模型；下载服务器只见普通出口IP。报告区分包身份、协议回归、原生GUI/付费推理未测试，不能把前两项称为整套原生功能验收。

## Existing note review

- [取消门禁](../../implemented/simplification/2026-11-01-accio-remove-version-gate.md)：保持用户入口放行，自动化报告不成为新白名单。
- [0.37.1协议与工具修复](../../implemented/bug-fix/2026-10-30-accio-0371-compatibility.md)：复用已有隔离协议测试，保留原生证据边界。
- [版本查询与诊断](../../implemented/feature/2026-10-30-accio-readiness-diagnostics.md)：复用固定源、查询限额；不恢复客户端自动提示或未实测禁用。

## Alternatives considered

- 每版人工重复GUI验收：覆盖真实交互，但重复成本高且需要账号与付费，保留给关键变化。
- 仅比较版本或整个包摘要：便宜，但无法区分无关打包变化与模型协议变化，不作为兼容成功依据。
- 官方身份校验加关键AST结构匹配与已有离线行为测试：减少重复操作，遇真实变化报告待复核，采用；仍不能代替原生任务验收。

2026-11-01官方更新源返回0.37.2，ARM64 ZIP为249136863字节，SHA512与官方元数据一致；codesign严格验证官方Bundle ID与Team ID通过，包内版本一致。worker SHA256为2cea95e2687b5e249e8e42c93d7266084318f3b2571a07f4a8dee483179a3fd4。以0.37.1已审阅程序生成102个声明指纹，0.37.2与0.37.1都完成目录/模型/工具/SSE/错误/取消16项检查，externalRequests=0、timersRemaining=0。完整下载到报告命令实际返回protocol_passed；原生GUI、官方登录和真实模型推理未运行。

6项Node对抗测试覆盖一致重命名、属性/字符串/运算符/新增语句变化、歧义与缺失声明、跨声明依赖不一致、工具完成条件唯一性以及全局能力不得重命名。8项Python测试覆盖固定源与单一资产、元数据限额/版本变化、安全归档、下载摘要/体积、ASAR边界、超时与错误脱敏、签名失败不执行协议及临时目录清理、超时同时结束子孙进程。现有3项元数据脚本回归通过。初始匹配受同形常量歧义影响，补模块归属、相邻已定位声明次序及共享依赖一致性才允许执行，没有采用首个匹配或放宽行为断言。

仓库只保存语法指纹、符号名和公开包摘要，不保存厂商程序或本机数据；执行器使用有界子进程与合成环境。源码取样及下载不启动官方应用，因此无电脑名称、手机号或官方会话上报；官方下载服务仅见通常的出口IP。工作流配置已本地完成，尚未推送部署，不能声称远端监控已开启。

工作流YAML及脚本格式通过；笔记包装脚本缺少Bun，使用Node运行相同三份校验器通过。收尾保留结构化公开摘要与本地提交，移除本次可重新下载的临时官方包/解包样本和依赖链接；测试子进程、计时器和临时检查目录为零。用户现有应用及个人虚拟机未修改。

## Consequences

离线桩无法覆盖官方登录、原生审批、云端电商及真实计费；关键未提取代码变化不属于协议证据。自动检查应使用隔离CI环境，不上传厂商程序、私人数据或原始执行错误。部署状态必须与本地实现分开汇报。
