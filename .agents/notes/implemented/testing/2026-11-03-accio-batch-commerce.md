# Agent Note: Accio批量电商文件验收

Status: implemented

## Problem

两商品历史样例已验证原生读写，但现有检查器只检查四个事实字段及全篇子串，不能可靠发现其他SKU混入预览、额外事实字段改写或非目标修订。不能由已有两条样例推广为批量工作流完成。

## Decision

扩展为六商品独立批量任务包，保留旧例和历史原生证据。任务目录外保存可信源副本、保护文件和初稿快照；检查器逐SKU比较全部源事实、输出字段、缺失信息、精确Markdown预览和单字段修订。提供明确准备、初稿核对、保留基线、修订核对命令；不存在通过检查即自动发布的入口。

预览增加原始事实表，两个相似SKU分别显示，供人工对照文案。供应商备注保留在JSON而不渲染成营销文案。Mac提供系统Ruby预览脚本，已有Node的环境使用JS入口；两者均拒绝符号链接输出并先完成渲染再写文件。新增离线回归进入CI，工具代码不改变Accio连接、用户模型或分组。

## Existing decisions

[商品工作流](../../implemented/testing/2026-10-31-accio-commerce-workflow.md)部分重叠，沿用合成资料、Astra、人工审批和零遗留；新增批量与更强验收，不改变历史实测记录。其他Accio协议、版本与安装笔记不负责文件验收。

## Alternatives considered

- 继续增加prompt约束：容易开始，但模型自述不能证明源文件未变或修订范围正确。
- 用模型裁判自动审核营销事实：能检查语义，但引入费用、不确定性与数据流；本次采用确定性结构/文件核验并保留人工审稿。
- 接真实店铺：更贴近业务，但需另行店铺授权和云端接入，不属于本轮本地文件工作流。

## Verification

15项离线测试通过，覆盖全部源事实（含false/0）、重复/遗漏/重排SKU、未知信息、额外字段、假发布状态、预览串货、畸形输入、定点修改越界、源与输出同时篡改、快照不覆盖、符号链接以及两种渲染器的一致性。测试只用明确标记的合成fixture，不把fixture当真实模型输出。

2026-11-03复用停止状态的专用QA虚拟机，确认Accio0.37.2、候选GUI0.1.121和Astra配置存在，未改配置。预检发现没有Node，因而补Ruby入口并在guest实际执行；六SKU预览与宿主Node输出SHA256完全一致。任务已放入guest独立新文件夹，可信副本只留宿主；未导入宿主个人资料或账号，没有模型请求。正常关机后两台VM均stopped，本轮测试进程为零。

首次准备阶段未完成六SKU原生执行；后续实测证据见下文，旧两商品记录不冒充本轮批量通过。

2026-11-04续验确认专用QA的Accio0.37.2、候选GUI0.1.121、既有Astra授权分组与六SKU任务完整，未有输出。随包Core摘要与原候选记录一致，管理接口受控启动HTTP200，未发推理请求。guest截图失败（could not create image from display），辅助访问被系统拒绝（-25211）；宿主按QA窗口精确查找也未取得可观察画面，因此未盲点输入/审批，不改变系统权限。活跃请求0后准确停止测试Accio；Core stop后即时零进程检查失败，未把该检查计作通过，随后正常关闭整个QA guest，监督器exitCode0确认guest stopped，客体测试进程随关机结束。没有在用户日常Core执行停止操作。六SKU真实任务仍待可见界面提交。

## Consequences

确定性检查不能证明自然语言文案完全无虚构或适合上架；必须人工审稿。任务工作目录只给Accio使用，reference属于维护者的可信基线而非恶意宿主隔离沙箱。新流程增加一次初稿快照与固定预览格式，换取可复查的修改边界；不覆盖旧文件，失败不自动重发模型请求。本次不推送发布客户端，跨平台及最新正式包验收不由候选环境推断。

## 2026-11-04 两阶段原生结果

用户要求停止抢占鼠标后，原生提交与审批由用户操作；维护者通过SSH只读提取限定任务目录，未自动点击或改写模型产物。目录为既有QA工作区中的独立六商品子目录，保留宿主可信副本。

第一阶段真实生成JSON/Markdown，六SKU和全部原始字段完整；六个保护文件字节不变、额外文件0、精确预览一致、活跃请求0。逐项审阅双语文案：保留支架无充电、玻璃杯不耐热、礼盒起订量100；没有将零库存或false当成未知，未知防水和认证仍列待确认。保存第一阶段输出作为独立基线。

第二阶段独立对象比较确认只有DEMO-BAG-01的title_en变为指定值，另五商品及所有其他字段不变；Markdown完整字节比较等于对应英文标题的一次替换。原始文件未改、额外文件0、活跃请求0。只读请求查询匹配当前启动scope与Core对子进程的归属，最近12条模型记录均gpt-6-astra、HTTP200、正输出、分组匹配且无记录错误，覆盖初稿末尾及修订；不将12条称为两阶段全部请求数。

此证据覆盖Accio0.37.2、Apple Silicon QA、已验证候选GUI/Core0.1.121及Astra，并非v0.1.126正式包的新安装验收。检查器的nativeExecutionVerified=false保留原语义：单靠文件校验不能证明原生执行，原生证据来自用户界面与独立路由记录。也没有全系统网络/文件审计，不能从模型自述断言没有任何其他访问。原始截图和请求证据不提交公共仓库。
