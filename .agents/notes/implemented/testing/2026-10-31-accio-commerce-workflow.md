# Agent Note: Accio 商品资料工作流与重启保留验收

Status: implemented

## Problem

已有Accio0.37.1本地文件链与停止恢复证据，但不能从合成算术任务推断电商商品资料工作流实用，也未验证退出重启后的显式模型选择保留。

## Decision

沿用已有Apple Silicon专用QA机、官方0.37.1、已验证Core和Astra/鹈鹕王分组。建立两条合成商品资料及本地任务说明，原生执行读取、双语文案整理、结构化文件与Markdown交付，再根据要求修改一个商品。独立校验SKU/价格/缺失字段/禁用承诺及源文件未变。重启前记录官方菜单选择和元衡业务配置摘要，退出后从Core受控重启，不修改用户日常VM或宿主工作区。

先使用Astra付费任务，菜单可选其他型号但不发送其他模型请求。只用本地合成数据，不调用官方云端连接器、网络搜索或上架发布。模板沿用仓库指南与样例目录，不创建一套业务API，也不修改伙伴正在编辑的媒体文件。旧Core原生结果明确归属，不冒充当前未发布源码安装包验证。

## Existing note review

- [0.37.1兼容](../../implemented/bug-fix/2026-10-30-accio-0371-compatibility.md)：复用可选工具参数修复与官方身份检查。
- [兼容预警与控制验收](../../implemented/feature/2026-10-30-accio-readiness-diagnostics.md)：补充电商与重启证据，不重写停止验收结论。

## Alternatives considered

- 仅用普通聊天生成文案：最快，但不能证明读取真实源文件、写入及修改成功，不采用为验收依据。
- 直接连接真实店铺：更接近业务，但需要官方云端授权且会扩大数据和发布权限，当前不做。
- 原生应用对合成商品资料执行完整文件任务：可复查、不涉及真实商户数据，但不能代表所有平台、商品品类或模型均通过。

## Verification

- 两个SKU完整，价格/材质/尺寸等关键事实不变，缺失事实不杜撰，保留校验标记。
- 双语标题、卖点、注意事项及Markdown文件真实写入；后续修改只影响指定商品和指定字段。
- 重启前后元衡业务配置保留、官方菜单选择可观察，最终恢复Astra。
- 限定调用与执行时间，审批逐次处理，测试结束App/Core/临时服务0，VM正常关闭。

2026-11-01本轮原生验收使用官方Accio0.37.1及已验证Core95671f5a…，沿用专用QA已有配置Astra/鹈鹕王，不复制宿主个人账号或资料。首轮读取task.md/products.json，生成两个SKU的listing-draft.json及listing-draft.md并读回，10条模型请求全部HTTP200且正输出。独立导出仅三个合成商品文件，结构核验通过；人工检查中英文材质、尺寸、颜色、拉链/口袋、护理、手机尺寸范围与无充电功能符合源数据；防水、认证、承重列为未知，未虚构保证或上架结果。源文件SHA256不变、guard不变。

第二轮在同一会话读取明确revision.md，只修改收纳袋title_en，9条请求全部Astra/200/正输出。独立对象比较确认JSON仅目标title_en变化，Markdown完整字节比较等于一次对应标题替换，其余内容及第二SKU完全不变。虚拟键盘首次长指令乱序/截断，未提交；改为本地完整修订说明及短引用指令后执行，没有因此付费重发。

原生菜单改选gpt-5.6-luna但未发请求，确认无活跃请求后结束准确身份的Accio进程，再由原Core管理接口受控重启HTTP200。元衡profile除运行字段之外与前置备份相同；原生登录保留，重进商品会话显示gpt-5.6-luna，随后恢复gpt-6-astra。此结果仅证明应用进程退出重开后的同会话选择保留，不代表整机重启、版本升级迁移、另一模型推理或新安装登录恢复。

离线检查器3项测试覆盖正确草稿、价格变动、缺失信息、重复SKU、顺序变化、虚假published状态、Markdown不一致及错误语言字段，全部通过。机器校验始终返回requiresHumanReview，不将格式正确当作营销/事实自动审核。实际生成及修订输出均通过检查器。

收尾确认活跃请求0，准确匹配测试Accio进程后退出、停止测试Core；旧Core第一次恢复遇服务退出竞态，确认无运行Core后单次重试成功，核对旧二进制身份后停止。业务profile与本轮备份仅运行capability差异，active=false，Accio/GUI/Core进程0。专用VM正常shutdown，run-test监督器exitCode=0；个人VM未启动。格式与笔记三项校验通过，本轮没有修改产品接入源码，因此不重复全仓编译。

## Consequences

生成内容需要人工审稿；机器结构校验不能证明营销质量、合规或平台审核结果。官方升级、云端工具、Windows支持不属于本轮验收。

用户交付复用[商品工作流指南](../../../../docs/guides/accio-product-copy.md)、[合成样例](../../../../docs/examples/accio-commerce/products.json)、任务模板及本地校验脚本，没有新增业务接口或修改官方应用。当前仓库已有伙伴媒体保存改动，原样保留，不能随本次一起提交。未推送或发布安装包，原始测试账号/设备标识/日志不进仓库。
