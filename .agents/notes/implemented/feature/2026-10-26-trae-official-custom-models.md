# Agent Note: TRAE 使用官方自定义模型辅助配置

Status: implemented

## Problem

用户希望TRAE像现有Agent一样由元衡配置分组和主模型。当前工具注册、检测、配置和启动路径没有TRAE。官方国际版文档支持自定义OpenAI Chat Completions和Anthropic Messages，但没有在已读页面说明配置导入API或文件格式；仅添加下载入口不能兑现主模型接入。

## Decision

元衡使用TRAE官方自定义模型入口，当前产品能力是辅助配置，不是自动导入。工具管理复用现有模型/分组选择器，生成完整请求URL和模型ID、提供官方原生操作步骤；用户在TRAE内完成官方登录、密钥填入、保存和模型选择。Mac可复用安装缓存、默认/自选路径检测、安装观察及签名启动；不创建另一套账号，不修改TRAE应用包，不自动同步模型目录。只有确认可维护的导入机制并验证原生消费后才扩展为一键配置。

官方国际版3.6.4签名包已静态核验：模型弹窗支持Chat Completions、Responses、Anthropic Messages及Full URL；保存经带官方账号凭据的AddCustomModel/UpdateCustomModel服务，未找到公开文件导入契约。辅助入口指向同源元衡令牌管理页。选择分组不等于改变API Key的分组，该边界在说明中直接展示。向导不读取、生成、复制或提交密钥，不向TRAE发配置请求，不加入批量一键配置或已接通状态。

公开端点仅接受当前/历史元衡精确HTTPS来源及根路径或/v1，保持所选连接来源，不静默跨域迁移。协议由用户明确选择，不按模型名猜测。完整URL开关必须开启，避免TRAE再次追加/v1或接口路径。账号切换/断开清空选择，目录撤销立即使旧组合不可复制。

安装检测与模型接通始终分开。Mac启动每次用codesign校验Apple信任链、`com.trae.app`和Team ID `79M8227NKH`，以规范化绝对路径交给`open -a`，不允许传restart/cwd、不终止已有会话。失效自选路径不能静默回退到另一安装，同名假应用和指向其他App的符号链接不可通过。签名/启动子命令有15秒上限，超时kill并等待回收；错误不输出原生stdout/stderr或个人路径。TRAE不是托管ToolId，不进入批量模型配置。其他平台未验证官方启动身份时使用手动打开说明。

官方下载观察最多5分钟，关闭向导或点击停止取消轮询；发现安装只刷新本地缓存，不自动运行App、创建令牌或保存模型。选择路径晚于向导关闭返回时仍使缓存失效，避免下次看到旧路径；取消路径选择不修改任何设置。

调研只从官网及其下载元数据指向的官方CDN获取安装包，静态检查，不运行第三方安装脚本、不启动TRAE、不读取个人TRAE配置或发送真实模型请求。后续原生测试使用隔离环境与合成文件；如需要个人设备标识/目录等外发先告知。真实生成测试限定用户指定的Astra及独享/鹈鹕王分组。

## Existing note review

- [TRAE现状报告](../../../../docs/reviews/2026-10-26-trae-compatibility.md)是本决定的事实依据，随本轮证据更新。
- [工作台直接安装](../bug-fix/2026-10-17-workspace-direct-install.md)部分重叠：复用安装观察和检测缓存，但不把浏览器下载或已安装等同于配置成功；TRAE保留明确的辅助模式。
- [Accio主模型桥接](../../proposed/feature/2026-10-18-accio-primary-model-bridge.md)只在Agent目标上相关：TRAE有公开自定义模型能力，不能直接复用Accio私有网关协议或放行云端路径。
- [TRAE原生接入](../../proposed/feature/2026-10-26-trae-native-integration.md)部分重叠：本篇记录已完成的安装/辅助入口；自动模型配置和实际推理仍由提案保留验收缺口。

## Alternatives considered

- 仿照WorkBuddy直接写一个models.json：容易实现，但没有官方契约依据，可能无效或破坏用户配置，不猜文件名/字段。
- 只加下载与启动卡：提供入口快，但达不到主模型配置目标，不标记为一键接入。
- 修改官方应用或截获其全部请求：影响范围大且绕过已有公开入口；优先官方自定义模型能力。
- 先核验官方配置和导入方式：需要调研和原生验收，但能明确凭据、安全边界和版本兼容。

## Testing

2026-10-26：新增26项纯数据测试、9项向导交互测试和1项工具网格真实选择器回归通过；包含三种Full URL、跨域/用户信息/查询参数/路径混淆拒绝、旧分组或图像模型拒绝、账号切换、目录撤销、双击与迟到反馈、复制/外链失败不泄漏原生细节。全部前端157个文件/1076项通过，typecheck与renderer构建通过。测试只使用合成账号与模拟复制/外链，不读取真实密钥、不发推理请求。官方DMG已卸载，测试遗留进程为零。

同日原生续验确认官方3.6.4的Models页要求先登录，无登录不能添加自定义模型。独立VM安装、签名、系统信任、首次设置和官方登录页面可达通过；未提交真实凭据。安装入口相关新增18项前端及6项后端通过；全部前端1094项、相关后端110项（去重）通过，类型检查/renderer构建通过。代码测试覆盖同名未签名包、不同App符号链接、失效自选路径、重启/工作目录拒绝、取消、晚返回、双击、平台未验证提示、原生错误不泄漏。精确codesign requirement对官方固定包校验通过；这不替代元衡GUI按钮→TRAE完整端到端验收。

## Consequences

[国内版扩展](2026-10-27-trae-china-edition.md)替代本篇原先的仅国际版安装限制：共享辅助向导、各版本独立路径与精确签名；原国际版身份保持。国内版的真实模型调用仍未验收，不继承本篇国际版测试结果。

用户随后要求与Accio一起先交付试用，入口增加实验说明、逐模型添加/切换步骤及停止请求边界；不把复制参数等同于接通。直连原生验收和正式安装包归属[实验发布范围](../../proposed/feature/2026-10-27-agent-experimental-release.md)，未通过前不能从旧loopback成功推断线上配置已完成。

用户获得实际可填写的参数和清楚的操作步骤，避免猜文件格式、重复拼接路径或误称一键成功；代价是仍需在TRAE登录、粘贴专用Key和逐个添加模型，元衡不会自动同步所有模型。官网文档可能包含不同发行版功能，国际版与国内版必须分别核验。静态检查不证明原生请求、文件工具、流式取消或其他系统可用；Windows、Intel Mac及国内版均未验收。官方App启动可能发送设备标识、系统信息或工作区路径，后续原生测试应保留隔离与告知边界。

发现官方可维护的导入契约且原生验证通过时再重访自动配置；不能复制/解密用户登录态来替代实现。当前辅助向导可独立审查，Accio仍保持自身发布门禁；此次没有推送、合并或发布。
