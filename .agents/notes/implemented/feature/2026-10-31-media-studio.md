# Agent Note: 独立图片与视频创作入口

Status: implemented

Muse的时长、多图及大视频下载边界由[长片适配](2026-10-31-muse-long-multireference.md)更新；此前单图/30秒/所有成品64MB是初版边界，不代表当前文档规格。

后续[服务兼容修复](../../implemented/bug-fix/2026-10-31-media-service-compatibility.md)将视频提交等待改为600秒，禁用Veo Lite与Omni720p，并替代本篇图片“只处理内嵌、不接URL”的限制。其余任务、账号和不重放约束保留。

## Problem

直接创作图片和视频的用户不需要先安装 Agent 或理解 API。现有桌面图片能力是按工具绑定的 GPT Image Skill；移动生图只处理单张同步图片，不能承担桌面视频任务恢复。

## Decision

声音克隆下面新增图片与视频。复用当前元衡账号会话和设备令牌逻辑，使用通用名称的专属创作令牌，固定“生图和视频”分组，不改变聊天/Agent。目录来自当前账号该分组，提交前再验证真实令牌目录。凭据仅后端内存，不回传前端，不使用设备名称。

原生命令负责参数白名单、限长读取、固定平台域名、禁止重定向和单次 POST。模型按已确认协议配置，未知模型不猜测。参考图由用户选择，PNG/JPEG 校验，正文只发送用户描述和参考图，不收集其他本机信息。结果存本机私有目录，历史仅保留模型、时间、状态、任务号和令牌编号，不存提示词或参考图。预览/导出按当前账号记录读取，不开放任意本地路径读取。

提交前写入操作记录，同一操作 ID 不重复提交。超时或中断保留结果未知状态，不自动重发。视频保存任务 ID 后只查询原任务；页面可暂停等待，退出后重开可继续查询。轮询有间隔和上限，取消等待不承诺取消上游或退款。下载只请求平台固定内容接口，不将凭据发送给任意结果 URL。

## Existing note review

[独立图片分组](../../implemented/bug-fix/2026-10-23-independent-image-group.md)与[多工具图片技能](../../implemented/feature/2026-10-23-multi-app-image-skill.md)部分重叠，复用鉴权原则而不改变现有工具绑定。[移动客户端](../../implemented/architecture/2026-10-19-mobile-clients.md)保留独立移动生命周期。当前工作树诊断改动保留，不混入媒体行为。

## Alternatives considered

- 增强 Skill 最易复用，但仍需 Agent 且不满足独立创作入口。
- WebView 直接请求可减少原生代码，但会把凭据交给前端，视频恢复与下载来源边界更弱；采用原生白名单命令。
- 任意模型自由输入覆盖广，但不同协议/尺寸/参考图不可互换；显示当前授权且已有明确适配的型号。

## Verification

原生新增9项通过：型号参数和协议、参考图格式/大小、响应体限长和错误正文不回显、路径/任务编号约束、multipart、内嵌图片、记录账号隔离和重复提交拒绝。已有2项设备令牌及1项禁止重放/重定向回归通过。macOS arm64 GUI/Core 的 Clippy（lib、bins、-D warnings）与原生检查通过。没有执行全量原生测试，也没有验证 Windows/Intel 安装包。

前端最终全量166文件1185项通过，包含目录刷新不得静默替换用户模型的回归。媒体/侧边栏/翻译针对性23项通过，涵盖加载无权限、重复点击、参考图必选、未知提交、查询故障、最多40轮查询、账号切换、导出和blob回收。假时钟测试卸载后剩余timer为0。类型、renderer构建、Prettier、Rust格式、差异检查和决策笔记检查通过；构建保留既有chunk体积提醒。

实际Vite渲染配合隔离模拟IPC，1280×720和800×650下图片/视频切换、尺寸时长展开、提交模拟任务、滚动记录、暂停/继续查询通过。模拟接口不携带账号或密钥，不产生收费调用；不以模拟成品证明生产端到端可用。

临时模拟页面和fixture已删除，预览页关闭、Vite退出，视口恢复。合成验收截图保存在本机临时目录，不含真实账号和作品；没有将其加入提交范围。

最终类型复验发现新增测试误用了Testing Library不支持的exact选项，已去除；随后类型检查与媒体10项测试通过，生成代码未改。结束检查测试/构建/预览遗留进程为0，其他项目原有服务未干预。

## Adversarial review

- 账号分组目录与真实令牌目录分别验证，固定组缺失不回退。凭据复用函数的新命名参数不改变原Agent设备令牌名称；媒体名称不读取电脑名称。
- 重复操作在任何网络请求前拒绝，持久化后再次校验；ID只接受规范UUID，防止大小写绕过。POST禁止自动重试/跳转；未知结果保留，不自动换模型。
- 图片只处理内嵌数据；视频只向平台固定content路径下载，任务ID拒绝路径/查询注入，不跟随任意CDN地址。正文和成品有界读取，不回显上游错误正文。
- 本机媒体目录及文件拒绝符号链接，文件权限收紧；预览/保存/删除互斥，删除不能被进行中的下载重新写回。记录更新不复活已删除记录，提交期间禁止删除。
- 前端离开/切号忽略旧异步结果并释放blob；暂停或卸载停止后续查询，已发出的有界原生请求最多等自身超时结束。刷新模型目录不偷偷替换已选模型，必须重新选择。

## Consequences

供应商模型目录不是能力保证，首帧兼容尚未上线确认的 Grok 暂只支持文生视频。结果下载依赖平台内容接口；外部 URL 不自动跟随。本地作品占磁盘，需提供删除；模型价目表不能可靠精确估价时只明确按实际用量扣费。

首版只展示明确协议配置与授权交集，不承诺平台所有型号；每成品64MB、50条记录上限约束本机占用，超限保留任务记录而不重新生成。真实生成仍需用户明确授权后的生产验收。本轮保留前一批P0诊断改动，未推送、发布或改动生产配置。使用说明在[创作指南](../../../../docs/guides/media-studio.md)。
