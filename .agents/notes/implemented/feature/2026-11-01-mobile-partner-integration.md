# Agent Note: 移动端伙伴界面与业务扩展安全合入

Status: implemented

用户随后授权推送并发布安卓APK；准备0.1.0-alpha.2、versionCode=2，沿用正式签名和现有移动构建/分发入口。发布状态由实际工作流及资产核验决定，前述本地验收边界保留。

## Problem

用户提供安卓改版源码并要求在本地项目整合。伙伴增加模型广场、控制台日志、图片收藏/复用、令牌编辑、兑换码创建和奖励划转；APK并非纯UI且签名不同。审查发现收藏共用目录、纯文生复用残留参考图、兑换码重开丢失幂等ID。

## Decision

复用mobile现有账号与固定origin接口白名单，导入伙伴src与两原生模块及已有回归，不复制签名、构建配置/版本或凭据。收藏由原生当前登录账号决定目录与读写权限，IO期间持有登录锁防切号，未知归属旧gallery不迁移，40条/80MiB总额与64MiB单条上限，原子写入和符号链接拒绝。

兑换码保留服务端request_id幂等设计，前端按账号持久化仅quota/requestId，在发送前可靠写入；响应不确定不清除，不允许改额度开始新操作；关闭/重启后恢复，同额度用同一ID。后端成功且结果确认才清理，清理失败仍保留原ID，不储存兑换码/密钥。已有未决操作直接重试，不因服务端已扣额度导致余额/次数预检阻断幂等结果读取。无持久存储不发送扣费请求。

生图复用完整替换参考图，清理FileReader旧结果；保留伙伴明确的并行生成，但限制本机4任务和内存结果保留，收藏/删除串行且失败不伪装成功。iOS购买限制仍由原生和UI同时守住，邀请划转不新增iOS开放。新增页面沿用现有模型/额度接口，不复制后台定价。

## Existing note review

[移动客户端](../../implemented/architecture/2026-10-19-mobile-clients.md)部分扩展：保持平台隔离/安全存储/真实验收边界；[安卓分发](../../implemented/process/2026-10-19-android-website-delivery.md)不变；桌面媒体和SQL保存修复无关，不改。

## Alternatives considered

- 直接用伙伴APK：无法保持正式签名覆盖更新，也无法修复已知问题；导入源码后本地检查。
- 收藏仅前端按userId过滤：可轻松绕过且磁盘数据混用；原生按当前会话隔离。
- 重开后生成新兑换请求ID：实现简单但超时并非失败，存在重复扣款；保留原ID直到确认。

## Verification

移动前端40项通过：伙伴原流程/价格/令牌测试与新增11项安全流程、2项原生IPC账号契约；覆盖超时重开原ID、成功后清除、旧响应晚到保留恢复依据、零余额拒绝新操作但可取原结果、存储损坏/写入失败不发送、账号隔离、并行锁、参考图复用/晚到FileReader拒绝、删除失败不隐藏、同参数防重复与4任务上限。React异步测试清理顺序修正后无act警告。

原生15项通过：收藏目录账号隔离、无归属旧目录不导入、数量/容量、原子覆盖、MIME错误/符号链接拒绝；发起账号校验拒绝晚到旧账号命令；iOS新增奖励划转封闭。所有测试使用临时目录与合成数据。macOS宿主Rust lib测试/Clippy（lib/bins、-D warnings）、pnpm10.12.3固定锁文件安装、TypeScript、Vite构建、前端Prettier、Rust格式与diff检查通过。Cargo仅增加已锁定tempfile直接依赖，桌面及移动前端锁文件不变。

通过临时本地模拟IPC在390×844检查广场/控制台/账户入口，模拟兑换码超时并关闭重开保留原操作；320×568测得document/body/dialog宽度均320，无横向溢出。保存合成效果图，不含真实用户或余额，临时页面删除、浏览器标签关闭、视口恢复、开发服务停止。不宣称Android/iOS真机登录、相册或收费接口已验收；没有修改版本号或签名，也没有打包、推送、发布。

## Adversarial review

- 收藏命令不仅从当前登录取目录，也要求前端发起userId匹配，登录锁贯穿同步IO；否则切号后排队命令可能把旧图写入新账号。钱包创建/划转同样校验expectedUserId。
- 结果未知不能等同失败。幂等ID在POST前可靠持久化，未决恢复跳过新操作余额/次数预检以免第一次成功后无法确认；关闭时迟到成功不清除恢复记录，不缓存兑换码。只有用户明确核对平台后才能放弃旧记录开始新操作。
- 伙伴收藏只有读取限制，本轮增加写入40条/80MiB上限和临时文件原子保存；前端80MiB结果保留防止60张大图无限占内存，旧收藏不删除或猜归属。
- 并行生成仍可用，但完全相同参数在执行中不重复提交；停止只取消本机等待，不声称退款。所有移动HTTP显式禁用隐式重试和重定向。
- iOS原生和UI同时拒绝新增财务入口，模型/令牌权限继续依赖后端，公共价格目录不作为授权依据。

## Consequences

已安装伙伴测试签名包的历史收藏无法可靠判定归属，不自动归到首个登录用户。持久化幂等记录需用户保留应用数据，清空数据后仍须平台记录核对。平台接口部署与真机交互尚需验收，移动共享源码影响iOS界面但不放开购买路径。
