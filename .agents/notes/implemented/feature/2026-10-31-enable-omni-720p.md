# Agent Note: 按用户确认开放 Omni 720p

Status: implemented

## Problem

此前因提交验收未确认，客户端屏蔽Omni720p。用户现明确确认“这个可以了，开放吧”，继续屏蔽不再符合当前要求。

## Decision

恢复精确型号flow-video-gemini-omni-flash-1.1，复用已有seconds/size协议，4秒、1280x720或720x1280，仅文生视频，600秒单次提交。仍需生图和视频分组目录与真实凭据授权。用户确认是此次开放依据，不伪称本轮执行过线上生成。

## Alternatives considered

- 继续屏蔽：保守但忽略用户最新确认，因此不采用。
- 同时开放参考图或任意时长：覆盖更多功能，但用户确认不构成这些参数的能力证据，保留既有协议范围。

## Verification

媒体原生18项通过，新增两个方向的实际payload断言、错误时长/尺寸/参考图拒绝；生产构造器600秒POST断言纳入Omni720p。GUI/Core Clippy（lib、bins、-D warnings）通过，Rust格式及差异检查通过。前端沿用动态目录，不新增前端逻辑或重复全量测试。没有发收费请求。

## Consequences

此决定仅替代[兼容修复](../../implemented/bug-fix/2026-10-31-media-service-compatibility.md)和[图生流程](../../implemented/feature/2026-10-31-image-to-video-workflow.md)中的Omni720p屏蔽。Veo与Grok首帧限制保留。本地开放不等于安装包已发布。
