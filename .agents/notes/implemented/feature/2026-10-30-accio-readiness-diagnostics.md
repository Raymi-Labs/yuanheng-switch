# Agent Note: Accio 配置前兼容状态与官方版本预警

Status: implemented

## Problem

用户在官方更新后才由配置错误发现版本不兼容；已有安装缓存、版本预检及脱敏错误分类未形成完整的提前提示。模型HTTP200也无法证明官方工具执行成功，不能把等待审批误标为模型故障。

## Decision

复用工具状态的本地安装提示，增加结构化Accio兼容状态，工作台与工具管理共用显示和禁用规则。支持版本以Rust门禁为唯一来源；显示版本不是签名认证。配置/启动仍执行原来的完整预检，未知/失效路径不允许绕过。

独立只读命令查询固定官方macOS beta更新源，限制响应大小、超时、禁止重定向及原始错误回显；单飞缓存成功6小时、失败5分钟，旧成功结果明确标旧，不阻塞工具清单。不下载或执行官方程序，不传账号、设备名或本地路径。官方服务器仍可见普通网络请求出口IP。前端仅Accio可用平台展示查询，使用共享query缓存。

增加可手动/定时运行的仓库只读版本检查，未知官方版本令检查失败并产出报告，已有摘要锁定协议脚本保持拒绝未知包。不自动放行、自动收费模型测试或上传本机数据。本轮只落地本地代码，定时工作流未部署即不声称已监控。

扩展已有Accio错误分类的处理建议，区分额度、限流、过载、认证、工具schema、上下文、网络及取消；仅静态词表。生效信息明确模型成功不代表工具成功，提醒等待官方应用的逐次审批。停止/切换先沿用已有隔离回归，不编造原生验收。

## Alternatives considered

- 将官方请求塞进全工具状态轮询：实现简单，却使慢网拖慢全部工具，拒绝。
- 只在配置失败后提示更新：无额外联网，但无法提前预警，保留为最后防线而非唯一入口。
- 自动接受官方最新版本：更新无感，但签名无法证明协议兼容，拒绝。
- 读取所有官方聊天日志判断工具审批：信息更多，但涉及隐私和脆弱日志格式，暂不做；明确当前可观察边界。

## Verification

- 两入口显示一致；未知版本不能被配置按钮误导；未安装、未识别、未知平台分别处理。
- 官方超时、非200、重定向、超长/重复/畸形version不伪装成功，失败保留明确过期的旧信息。
- 缓存并发与失败退避回归，未知版本监控fixture失败，无收费外部请求。
- 错误分类安全与用户建议回归；相关前端/Rust验证，测试进程0。

本地67项Accio Rust回归通过：本地HTTP覆盖200、重定向不跟随、503、响应过大及超时；真实单飞夹具覆盖并发共享及失败退避；兼容状态缺失/未知/已验证分支、路径/签名/启动/撤销与三协议隔离沿用回归。首次新增HTTP断言的错误类型比较未编译，修正断言后全组通过，没有放宽产品校验。

相关前端71项通过，覆盖两个入口未知版本按钮、批量选择、失败提示、过期信息、共享查询及其他工具；TypeScript、format:check及生产renderer构建通过。官方0.37.1摘要锁定的15项SDK协议复验通过（模型覆盖、SSE、工具、取消读者/控制器/计时器），外部请求0、遗留计时器0；不代替原生菜单切换或停止按钮验收。版本检查脚本3项离线回归通过，一次官方公开元数据查询返回0.37.1且requiresCompatibilityReview=false，无应用下载或凭据发送。

工作流仅写入本地，未推送，因此定时检查尚未生效；每6小时查询、未知版本失败报告，不自动下载新版程序或创建收费候选验收。未触发GitHub消息/Issue，无法保证所有官方更新都在用户升级前完成验证。actionlint本机不可用，工作流使用已有固定checkout提交与最小read权限。

最终GUI/Core `cargo check --offline --locked --lib --bins`及相关文件rustfmt通过，工作流YAML解析通过；Bun缺失，笔记三项校验器由Node执行通过。收尾未发现cargo/rustc/vitest/临时HTTP服务或VM管理测试进程，本轮未启动虚拟机、未调用付费模型；没有推送或发布安装包。
