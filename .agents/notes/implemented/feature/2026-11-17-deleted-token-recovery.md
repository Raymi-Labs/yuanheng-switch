# Agent Note: 在客户端恢复误删的统一令牌

Status: implemented

## Problem

已记住的 ID 从平台消失后，普通请求主动停止创建凭据；用户不得不手工创建同名多组令牌，旧工具还可能继续使用失效的密钥。

## Existing capabilities and impact

体检、账号令牌分页查找、创建前持久标记、模型目录验证、按工具配置与官方账号模式均已存在。扩展体检的主动修复；[账号统一令牌](../architecture/2026-11-08-account-shared-token.md)的普通查找规则保留，本文只替代其“主动修复仍需去平台建令牌”的限制。[旧分组修复](../bug-fix/2026-11-02-credential-group-repair.md)仍保留验证后保存及正常工具不重配的边界；图片 Skill 专用凭据、媒体创作页和账号会话校验相关笔记不受影响。

## Decision

明确确认恢复后，完整查询当前账号列表，复用唯一替代项或创建一枚默认统一令牌。确认前显示新令牌使用当前授权分组和账户余额，不设单独额度、有效期或模型限制。后台和普通配置不复活删除项；停用、过期、耗尽及路由异常的已存在令牌也不替换。

体检按实际 HTTP 状态判断：401 只使活动托管工具进入待确认列表；网络异常、403 和健康凭据不替换。写入前必须证明旧密钥指纹匹配；缺少指纹（包括旧的 legacy 标记），只恢复通用凭据，具体工具交由用户显式配置。替代项通过模型目录验证后才记住其 ID 和指纹；验证失败保留原关联，避免错误替代项堵住后续恢复。账号或本次同步开始时的工具模型、分组、推理设置、旧密钥发生变化时停止写入。

Codex两端和Claude Desktop只更新其本地网关的托管凭据；WorkBuddy只替换匹配密钥；其他CLI沿用Provider更新投影，DSH沿用已有带备份校验的配置事务，Accio保留当前租约。不会重新启用图片Skill、启动工具或发送生成请求。部分失败在客户端明确显示并刷新缓存。

## Alternatives considered

- 遇到 401 即后台补建：错误响应不能证明令牌被删除，也无法区分有意撤销。
- 只修复通用凭据：无需碰工具，但用户仍需逐一重配。

## Verification

独立审查产生的两个失败用例已在本地复现并修复：旧版无指纹、无关失效凭据不能被迁移；手动替代项 B 目录返回 403 后换成可用 C，仍保留 A→C 的关联，无额外创建 POST。单工具无法读取不再中断整份报告；体检失败仍可显式只恢复通用凭据。前端验证本地化的部分失败提示，不宣称全量成功。

本地HTTP模拟先复现主动恢复被旧ID阻挡，再验证误删→补建→WorkBuddy文件更新→从文件取新凭据通过模型目录；重复恢复只发一个创建POST。已知旧密钥不同、健康密钥、切换账号、创建结果未知、停用及同名歧义回归保留。Codex独立端及原目录保留有独立测试。前端检验明确确认、失效工具范围、失败复验不报成功。原生账号模块、类型与renderer构建通过；没有真实用户令牌操作或付费请求。

## Consequences

多设备并发首次创建缺少服务端幂等约束；不宣称跨设备原子唯一。只恢复本机体检和确认列出的工具。历史配置无密钥哈希时存在受控迁移边界；未知/官方模式及无法确认所有权的配置需要单独处理。已被删除的令牌自定义额度/模型限制无法从列表还原，新建使用已展示的默认规则。外部CLI若缓存环境需要重新打开，客户端不强退正在工作的工具。平台token缓存传播与三平台真实进程热加载未实测。
