# Agent Note: 模型选择器分组与搜索层级

Status: implemented

## Problem

长模型目录混排，厂商在每一行重复，当前/推荐和元数据缺少层级。用户需要保持已有切换安全性而更快定位模型。

## Decision

复用 ModelPicker、modelVendors、cmdk 和现有 onChange/onRefresh：当前模型独立分区且只出现一次；其余按现有厂商识别分组。固定搜索/厂商按钮，列表独立滚动；搜索与厂商过滤交集生效，数量与结果一致。组内保留已有排序，不再宣称“新版本在前”。不额外添加不存在的当前/推荐模型，不更改 available 禁用语义，不触发额外配置或付费请求。本地模型/厂商收藏与真正令牌分组入口的收藏见[本地收藏](2026-10-04-model-picker-favorites.md)，其常用分区优先于其余厂商组，不替代当前区。重新打开重置搜索筛选，后台刷新保留展开状态。

## Alternatives considered

- 新建独立模型管理窗口空间更大，但会分叉现有切换链路并增加跳转；共享组件改造覆盖全部入口。
- 收藏、价格、能力排序可提供更多信息，但缺少本轮授权的数据语义且增加复杂度；原决定只整理厂商与现有元数据；明确授权后的本地收藏由[后续决定](2026-10-04-model-picker-favorites.md)负责，不添加价格与使用频率推断。
- 保留 cmdk 自动评分排序改动较少，但会打散分组和当前置顶的可预测顺序；显式过滤，键盘选择仍复用 cmdk。

## Verification

新增 4 个组件回归覆盖分组去重、当前/推荐标签、厂商和名称搜索交集、空结果清除、禁用项、刷新厂商消失和重新打开重置。保留原先刷新成功/失败不卸载弹层测试；更新应用集成测试的搜索提示文字，原切换流程仍通过。全量前端 840 项通过，TypeScript、格式与 renderer 构建通过。

独立 Chrome 模拟目录验证：连续 8 次真实滚轮，列表 scrollTop 增长、搜索输入位置不动；后台刷新仍展开；厂商与搜索交集、空结果/清除、键盘 ArrowDown/Enter 选中原模型 ID、Esc 关闭；360px 窄屏弹层边界不溢出。截图已本地检查，预览服务器与浏览器退出。无真实账号连接、配置写入或收费请求。本轮不推送发布。

## Consequences

厂商归属沿用模型名启发式，不是上游可用性或官方身份认证。数值元数据仅展示调用方现有信息，不生成价格或新能力声明。筛选为显式子串匹配而非模糊评分；当前模型同样受筛选约束，清除即可恢复。厂商按钮横向滚动以避免过多厂商挤占列表高度；当前分区是列表首项而非始终固定，搜索和筛选固定。
