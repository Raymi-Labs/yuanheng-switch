# Agent Note: 移动单模型对话显式速度档位

Status: implemented

## Problem

服务端main已明确service-tiers-client协议，移动聊天尚无档位、能力查询和按对话快照。用户要求实现并发布，不能以全局Agent配置代替每对话付费选择。

## Decision

扩展mobile Chat→api→原生白名单，能力按账号/模型/分组查询，无缓存跨账号复用。标准省略service_tier，priority/ultrafast按能力返回倍率开放；查询失败及支持撤销不自动降档。原生付费发送前再次查询和校验倍率，后端仍负责最终路由和扣费。重试复用原模型、组、档位及消息快照，不取当前选项，不自动重发。新对话标准，旧字段缺失标准，当前选择按账号对话持久化；消息保留已选档位而非加速已确认。不估算绝对价格、不修改计费Token。只修改移动客户端，桌面外部Agent无会话粒度入口。

## Alternatives considered

- 桌面全局开关：简单但跨会话付费污染，不符合约定。
- 根据Astra或1657硬编码支持：无需能力接口但不可反映账号授权、渠道关闭，不采用。
- 复用移动单对话发送与原生账号认证：最小作用域，标准对旧服务兼容，采用。

## Verification

标准不传、Fast=priority、UltraFast=ultrafast；404/离线/切组/切号迟到响应拒付费；会话恢复、重试快照、查询失败不降档；原生身份与能力复核。合成测试、浏览器、构建及签名发布分别验证，测试遗留进程零。

移动单模型Chat为唯一已有直接发送入口，桌面是外部Agent配置，无同类会话发送界面，不新增全局付费开关。复用ChoiceSheet和参数区域，付费倍率取能力响应并核对当前协议的2/6，变化则明确拒绝；绝对价格不猜测、不显示免费。已有复制功能只复制回复正文，没有请求预览/代码导出入口，本次不另建入口；所有模型发送由buildChatBody构造。保存每次答复的请求快照，用户明确重试时重新验证同模型/组/档位/倍率；停止只停止等待，不承诺退款。

前端合成测试覆盖三档映射、404、倍率异常、按对话保存/恢复/新建、切组撤销、切号迟到响应、原参数重试、发送前撤销与复核期间取消。原生新增同模型/组/倍率能力验证和查询URL编码测试；保留原账号/财务/媒体回归。生产dist真实Chromium模拟IPC验证三档请求、能力撤销后拒发、新会话标准、小屏布局和媒体已有流程；外部请求0。测试回执与最终数量随PR发布记录核对。

本地57项前端、19项Rust测试通过，Clippy -D warnings、类型/Vite构建、格式和diff检查通过。笔记包装入口缺少Bun，以Node执行同三份门禁通过，CI补验证。真实浏览器断言三档实际IPC body、撤销支持后不发及新会话标准；所有浏览器/HTTP/测试编译进程退出。准备alpha.5/versionCode5，未使用收费模型或宿主账号。历史兑换测试act警告仍存在，断言通过，不隐藏为无警告。

Impeccable沿用已有视觉系统，机械检测无命中。PR说明使用pr技能证据结构并保留仓库模板栏目。没有使用Muze Key、没有启用渠道1657、没有部署服务端；后端路由/计费仍为必要条件。
