# Agent Note: 创作工作台类型偏好、参数与再次编辑

Status: implemented

## Problem

媒体分组已过滤空/文本组，但图片视频共用一个选择，切换反复重选；目录被分组筛选/选择/模型读取重复请求；参数过少且隐藏；说明冗余；历史无法恢复创作描述和参数。用户要求P1至P2全部本地完成。

## Decision

### 范围与基线

从伙伴最新main 30d56bcc独立工作树实现。复用MediaStudioContent、媒体IPC、原生profile、共享令牌和历史，不新建付费路径。账号统一令牌的routing_config决定实际路由，UI分组只筛目录；更名“模型分组”，历史显示“所选分组”，不虚构最终计费组。伙伴的固定令牌、权限与旧任务token_id不改变。

### P1：类型与选择

图片/视频分别保存账号隔离的非敏感偏好（组、模型、size/duration/quality/resolution/outputFormat/background/compression）。不保存描述、参考图或令牌到偏好。类型切换保留编辑中的文本和参考图，不因新目录尚未加载丢失内容；恢复该类型已明确选择的配置，无偏好不跨组自动选择。旧共用组迁移仅作为有权限且支持相应类型时的兼容默认，失效偏好不回退。

灵感页允许图片/视频分组合集，进入工作台按当前创作类型过滤。更换分组保留旧模型，失效时要求重选，不把首个型号当静默回退。相同模型参数按账号/类型/组隔离，跨账号清空前端状态。

### P1：参数

原生profile是UI选项与提交校验共用事实来源。GPT Image开放quality/output_format/background/output_compression；2.5两型号增加xhigh/max、常用高分辨率与符合官方规则的自定义尺寸。2.5自定义边长16倍数、比例1:3至3:1、单边≤3840、面积655360至8294400；>2560×1440为官方实验范围，信息帮助说明，不静默降级。旧GPT按型号保留其已确认尺寸，不把2.5规则套到旧型号。

Gemini 3.1 Flash支持512/1K/2K/4K与官方比例，3 Pro支持1K/2K/4K，2.5 Flash保留1K并开放官方列出的比例。Grok视频按型号提供480/720与1.5的1080分辨率、官方比例，时长按已核实规格；Muse继续4–180秒和720p、Omni固定已适配档位。保持现有参考图能力，不宣称本轮实测云端生成。参数分别写入Images JSON/edits multipart、Gemini imageConfig、Grok视频payload，未经支持的字段原生拒绝。

### P2：目录与刷新

分组查询在原有有界并发中同时返回每组模型与图片/视频能力；前端按账号Query缓存60秒，模型查询用该快照作为initialData。分组刷新整批重验，模型刷新只查当前组。切换只验证快照归属后持久化偏好，不创建令牌；正式生成仍实时重查权限、分组目录和令牌目录。失败不展示旧缓存为最新权限，未知组失败独立提示。换号隔离，过期响应不能替换新选择。

### P2：再次编辑与隐私

历史新增可选草稿快照，数据库保存参数与描述保存标记、描述单独存本机账号媒体目录的.prompt文件，读历史时加载且不进入数据库导出。保存模型、所选组、参数、是否用过参考图（不保存图片）。只有生成表单显式勾选“保存描述到本机”才写入提示词；默认关闭，提示说明仅本机，可随记录删除。可单独删除已保存描述，不删除成品；记录删除同时移除快照。描述不进入日志、发布附件和偏好。

“再次编辑”只填草稿不提交：原组/型号失效时保留原意图并禁生成；旧记录无快照可恢复型号与组，提示补描述/参数；有参考图的原请求必须重新选择参考图，不假装复现。覆盖当前文本/图需确认。原视频轮询按原任务继续，不因编辑重发。快照解码使用serde默认兼容旧记录，不改历史50条限制。

### P2：界面

保留现有画廊与配色。移除slogan、重复当前组徽标和静态教学段落。表单直接显示型号、比例/尺寸、分辨率/质量/格式、视频时长；少用“更多设置”。说明集中到可聚焦、可点击的info帮助；表单标签、读屏名称、失败状态、保存描述后果和计费提示保留。无模型空态指出当前类型，可切换类型或组。

### 交付顺序与验收

1. 原生模型profile/请求与快照契约，添加每种协议的校验和序列化测试。
2. 分组目录快照、按类型偏好及旧设置迁移；验证缓存不绕过提交权限。
3. 前端类型切换、参数表单、再次编辑、清理文案与五语言。
4. 行为测试覆盖无偏好、失效偏好、旧目录晚到、切号、参数记忆、历史恢复和不付费提交；原生测试覆盖旧记录、prompt opt-in、删除描述、不保存参考图及非法参数。
5. 全量前端、相关原生、Clippy/格式/构建/笔记；浏览器以模拟IPC检查真实组件，宽窄窗深浅色与键盘。最后关闭自己启动的测试/预览进程，遗留为零。代码仅本地，不推送发布、不真实生成。

## Alternatives considered

另建一套媒体页面会复制状态和权限，继续扩展现有控制器。仅前端开放参数会被原生拒绝或发送错误字段，profile同时驱动UI与协议。自动跨组找可用模型会改变用户意图，明确恢复偏好或要求选择。默认保存所有提示词虽方便，但改变既有隐私承诺，采用显式opt-in并提供单独删除描述。

## Verification

上述六项P1/P2均落地；兼容来源与实际生成验收区分；没有未经证实的计费组、自动跨组/降参/重发；旧记录可读，参考图不持久化；默认不保存提示词；测试结果和遗留进程为零。

## Consequences

分辨率/质量提高可能增加费用/延迟，明确生成计费；上游渠道可能拒绝官方支持参数，应如实报错不重试。高规格原生输出可能触发现有64MB资源上限，继续保护本机并解释限制。偏好写入按账号隔离，外部模型目录仍可能在提交前变化，由实时检查兜底。没有生产账号路由实测，仅代码/模拟HTTP验证其语义。
