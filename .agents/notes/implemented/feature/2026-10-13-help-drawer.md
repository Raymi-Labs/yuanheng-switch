# Agent Note: 使用说明收纳到全局帮助抽屉

Status: implemented

## Problem

短篇使用说明占用一个主导航位置，并在查看时替换正在操作的页面。用户希望减少导航占用，同时仍能随时查阅说明。

## Existing capabilities and impact

原 GuidePage（现迁入 [HelpDrawer](../../../../src/components/desktop/HelpDrawer.tsx)）已有内置快速开始、日常使用、排错与 FAQ；无网络和权限依赖。[DesktopSidebar](../../../../src/components/desktop/DesktopSidebar.tsx) 底部已有官网入口，[GlobalCommandPalette](../../../../src/components/desktop/GlobalCommandPalette.tsx) 可搜索说明页面，[App](../../../../src/App.tsx) 持久化主页面。复用现有 Radix Dialog 的焦点管理与侧面板样式，迁移内容而不新增数据源或 UI 依赖。

检索活动笔记未发现说明页的独立决策；工作台精简笔记只涉及工具操作去重，本次单独记录帮助入口与页面状态边界。

## Decision

主导航删除说明页，底部帮助与官网并排。帮助通过受控 Dialog 从右侧打开，保留当前页面及未提交输入；命令面板的说明入口改为打开同一抽屉。支持关闭按钮、Escape、遮罩关闭与焦点恢复。旧版保存的 guide 页面回退工作台。退出登录关闭帮助，模态期间不响应后台页面快捷跳转。底部官网继续使用原外链接口；抽屉不再重复官网按钮和静态说明版本横幅。短窗口收紧侧栏间距，底部账户和帮助固定显示，导航保留独立滚动兜底。

## Alternatives considered

- 顶栏问号：入口醒目，但顶栏已有工具选择、命令搜索、状态、语言、主题和设置，继续添加会挤压窄窗口。
- 设置内说明页：无需新增抽屉，但查阅需要离开当前操作，多一步导航且可能丢失未保存内容。
- 底部按钮仍切换整页：改动较小，但短篇内容仍独占工作区，不能边查看帮助边保留操作上下文。

## Verification

143 个文件、904 项前端测试通过，随后 App 与侧栏 39 项回归通过。覆盖主导航移除说明、帮助位于底部、同一内容通过命令搜索打开、关闭后的焦点恢复、子页面 Escape 不返回后台、旧 guide 页面回退及页面持久化不变。类型、格式、版本一致性与 renderer 构建通过，构建仅有既有大包提示。

真实应用壳通过 Playwright 配合模拟 IPC 验收：1280×900 与 900×600、明暗主题、关闭按钮与 Escape、命令搜索帮助、遮罩关闭、FAQ 滚动、设置页面未保存输入保留。帮助正文来自客户端内置常量，无远程依赖。浏览器预览使用模拟账号，不替代原生安装包与真实工具配置验收。

## Consequences

主导航保留业务页面，短篇说明集中到辅助入口；查阅帮助不卸载后台页面。抽屉遮罩期间不能操作后台，关闭后继续原操作。旧版本持久化的说明页回退工作台，不自动弹出帮助；说明没有独立页面历史。长篇文档需求若增加，应重新评估抽屉容量与检索能力。
