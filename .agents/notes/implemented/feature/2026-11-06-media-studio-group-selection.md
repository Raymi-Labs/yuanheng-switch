# Agent Note: 创作分组选择与请求快照

Status: implemented

## Problem

图片与视频页面固定“生图和视频”组，其他已授权分组无法使用。仅增加下拉框不能解决目录、令牌及实际计费不一致，切组/切号并发可能造成过期目录覆盖，既有视频任务也不能跟随新分组查询。

## Decision

分类型偏好、目录缓存、参数和可选本地描述现由[P1/P2工作台](2026-11-10-media-studio-p1-p2.md)扩展；历史“不保存任何描述”改为用户明确勾选后单独本地保存，不进入数据库同步。原账号/请求/恢复边界保持。

分组下拉候选现由[实际媒体目录过滤](../bug-fix/2026-11-09-media-group-catalog-filter.md)收敛，保留拥有已适配媒体模型的组，纯文本/空目录不再显示；账号隔离和不自动回退保持。

复用账号分组列表和ensure_named_api_token，不复用只面向GPT Image工具的imagegen_connection。新增媒体分组读取/选择IPC，按固定服务origin与账号哈希保存非密钥分组偏好；首次仅兼容旧组且须有权限，没有旧组则要求选择，撤销的保存偏好不回退。选择分组不创建令牌。

模型IPC与提交请求显式携带分组，原生再次核对组权限、模型目录、真实令牌目录并保持same_login检查。令牌复用按名称与分组匹配，不修改旧令牌。历史记录保存实际提交组，旧记录缺省为原固定组；查询/下载保持record.token_id，不读取当前偏好。

前端目录缓存按账号和组隔离；切换过程加同步锁，失败保持原选择并提示，切号丢弃结果。切组不丢弃描述/参考图，不自动替换已选模型；不支持的旧模型显示失效。分组控件在灵感/工作台可见，灵感权限与工作台统一，组加载失败及刷新时禁止提交。

## Alternatives considered

只存localStorage并改标签不能证明原生实际组，且WebView缓存不应决定权限；采用原生非密钥账号偏好加显式请求快照。

直接套用Agent图像连接会强制GPT图像筛选，排除只有视频的分组，并改变Agent连接；仅复用底层账号/凭据函数。

自动选择首个授权组或失败回退可减少点击，但可能改变计费和模型渠道；首次保留兼容默认，其余明确选择。

## Verification

原生媒体30项和凭据管理7项回归通过。新增测试覆盖显式group的HTTP目录查询、未授权组在目录请求前拒绝、过期登录拒绝、按账号保存且不改聊天配置、首次默认/权限撤销不回退、旧记录迁移保留token_id、旧任务在新组偏好下仍只读取原token端点、同名令牌严格按组匹配。测试使用隔离临时目录和内存数据库，不读取真实账号凭据。

前端新增IPC与用户流程覆盖组偏好恢复、空授权目录、不自动选择首组、切组保留描述/参考图、新组目录未返回禁止提交、旧组迟到响应隔离、失效模型不替换、切换失败保留、权限撤销、切号后的旧保存结果丢弃、提交中禁切换、旧视频继续查询。既有轮询与参考图回归保持。

浏览器验收使用实际MediaStudioPage与模拟分组/模型，无真实账号和收费请求：灵感卡片授权随组变化；视频专用组不会自动替换图片模型，手动切换视频类型可选Muse；空目录禁生成且提示当前类型的范围。1280×900浅色工作台与600×800暗色无水平溢出，控件在顶部可见。修正了仅视频分组在图片页被错误描述为“整个组无模型”的文案；暗色错误文字显式使用可读颜色。外壳是预览，不是原生安装包验收。

## Consequences

新组首次真实生成仍可能创建该组的专用令牌，这是既有提交机制而非切组动作。组倍率不等于最终价格，不展示未经证实的精确估价。不收费验证、不推送或发布。

## Adversarial review

- 分组偏好只影响新草稿，实际请求显式group，不从一个可变全局设置推断正在提交的组。授权列表不是付费请求的凭证，提交仍验证所选组、模型及真实令牌目录。
- 缓存键包括账号/组；切组采用同步锁，切号由现有scope重挂载并丢弃旧结果。读图、提交及作品操作期间不能改组。模型刷新不静默换型号，输入与参考图不因目录失败被清空。
- 不修改旧组令牌或历史token_id，查询/下载不依赖当前组偏好。不将模型目录查询或切组变成创建令牌操作；新组首次真实提交沿用既有凭据创建机制。
- 模型参数和数量上限未改，不把无适配模型误判成无分组权限；倍率不作为精确价格。
