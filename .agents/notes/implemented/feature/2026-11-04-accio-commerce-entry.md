# Agent Note: Accio商品示例客户端入口

Status: implemented

## Problem

六商品工作流已完成原生验收，但指南和维护者脚本不易被普通用户发现，要求另装Node运行检查也不适合小白。

## Decision

复用AccioConnectionNotice，在工作台与工具管理同级入口增加商品示例对话框。选择父目录后创建唯一的新任务文件夹，复制第一阶段指令；可选择已有任务，原生读取固定文件名并检查事实、保护文件和预览，初稿通过后显式保存不可覆盖的修订基线，再复制修订指令并检查第二阶段。

复用已验证六商品模板及Ruby/JS渲染脚本，构建时内嵌静态资源，不启动Node、不运行生成代码、不上传文件或调用模型。不自动启动Accio，不抢鼠标。所有文件写入只在新建任务中或显式基线保存，原生拒绝符号链接/超大文件/未知格式，取消选择不写入。失败结果必须保留初稿和用户输出。

## Existing decisions

[批量工作流](../../implemented/testing/2026-11-03-accio-batch-commerce.md)部分重叠，沿用事实契约与独立基线；本篇负责GUI/IPC/原生文件边界，不提高原生模型验收范围。其他Accio接入、版本和模型菜单不变。

## Alternatives considered

- 只打开网页指南：最小改动，但不能消除文件准备和检查门槛。
- 在客户端调用Node脚本：可直接复用检查器，但普通Mac未装Node，增加外部进程与执行面，拒绝。
- 原生固定文件操作和校验：无需依赖，代价是维护跨语言契约；以共同fixtures和渲染对照测试防漂移。

## Verification

全量前端169个文件1243项测试通过；新增6项组件流程覆盖其他Agent无入口、取消无创建、选择/检查/保存/复制完整流程、失败复查清除旧成功、连点单飞、取消保存和切目录清除结果。已有工作台/工具管理回归继续通过。

原生7项测试在真实临时目录覆盖中文路径、唯一新目录、完整初稿/基线/修订、false/0字段、源文件与基线损坏、缺文件、超4MB、额外文件、符号链接读写、跨语言预览fixture与不执行任务脚本。15项离线脚本测试、资源生成一致性、TypeScript、renderer构建、Clippy lib/no-default-features -D warnings、格式和笔记三项检查通过。本机没有Bun，使用Node24执行同一套笔记脚本。没有新模型请求或GUI虚拟机测试，不冒充Windows真机或新安装包验收。

## Consequences

reference是维护者基线而非隔离沙箱；检查不能代替营销/合规审稿，GUI只报告文件规则。Windows能准备/检查不等于支持Accio Windows配置启动，入口遵循Accio当前supported状态。

固定样例检查不接受用户随意改写的商品源；这是演示/验收工具而非通用上架编辑器，真实商户资料须另设契约。对话框内显示本地路径且提供显式复制，不持久化最近目录、不自动上传。JSON/Markdown固定文件各限4MB，未知目录内容拒绝，允许Finder产生的.DS_Store。OS目录picker取消不写入，创建使用私有随机新目录，失败清理仅限本次拥有的新目录。基线以create_new保存，损坏/中断留下的基线不会被当作有效结果或自动覆盖。本地恶意进程并发替换祖先目录不属于该工作目录约定的安全沙箱承诺。
