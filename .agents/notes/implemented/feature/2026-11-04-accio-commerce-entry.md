# Agent Note: Accio商品示例客户端入口

Status: implemented

## Problem

六商品工作流已完成原生验收，但指南和维护者脚本不易被普通用户发现，要求另装Node运行检查也不适合小白。

## Decision

复用AccioConnectionNotice，在工作台与工具管理同级入口增加商品示例对话框。选择父目录后创建唯一的新任务文件夹，复制第一阶段指令；可选择已有任务，原生读取固定文件名并检查事实、保护文件和预览，初稿通过后显式保存不可覆盖的修订基线，再复制修订指令并检查第二阶段。

复用已验证六商品模板及Ruby/JS渲染脚本，构建时内嵌静态资源，不启动Node、不运行生成代码、不上传文件或调用模型。不自动启动Accio，不抢鼠标。所有文件写入只在新建任务中或显式基线保存，原生拒绝符号链接/超大文件/未知格式，取消选择不写入。失败结果必须保留初稿和用户输出。

## Existing decisions

[批量工作流](../../implemented/testing/2026-11-03-accio-batch-commerce.md)部分重叠，沿用事实契约与独立基线；本篇负责GUI/IPC/原生文件边界，不提高原生模型验收范围。其他Accio接入、版本和模型菜单不变。

## Alternatives considered

- 只打开网页指南：最小改动，但不能消除文件准备和检查门槛。
- 在客户端调用Node脚本：可直接复用检查器，但普通Mac未装Node，增加外部进程与执行面，拒绝。
- 原生固定文件操作和校验：无需依赖，代价是维护跨语言契约；以共同fixtures和渲染对照测试防漂移。

## Consequences
