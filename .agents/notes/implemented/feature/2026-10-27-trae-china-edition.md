# Agent Note: TRAE 国内版与国际版的独立辅助入口

Status: implemented

## Problem

用户选择优先在本机使用国内版。现有辅助入口只接受国际版Trae.app、com.trae.app与79M8227NKH，国内版安装后仍会显示未安装。仅改下载地址会把检测、路径选择与启动留在另一发行版；两版混用签名条件又会放宽身份边界。

## Decision

本决定只记录本地安装/启动与参数向导的发行版隔离，不表示国内版模型推理已验收。复用现有TRAE辅助向导、安装观察、ToolModelPicker和桌面路径存储。向导显式选择国内版/国际版，默认国内版；保留原trae目标作为国际版，新增独立trae-cn检测与路径目标。切换发行版卸载旧安装观察组件，取消其轮询并抑制迟到反馈；不自动迁移Key或启动另一版。启动器按目标精确匹配bundle名称、Bundle ID与Team ID，并在规范化路径后再次核验。保留15秒子进程限时、失效自选路径拒绝和不强制重启边界。

国内版使用www.trae.cn/download与docs.trae.cn/ide_models。最初按当时证据只提供Chat Completions和Anthropic Messages并在切换版本时重置协议；[原生Responses验证](../bug-fix/2026-10-28-trae-native-responses.md)现替代该协议限制，两版均可选Responses，切换发行版保留共同支持的协议。模型服务域名沿用用户当前元衡连接，不因为国内版自动迁移密钥到cn域名。保持辅助配置状态，既不读取官方登录凭据，也不写入未知本地模型数据库。

## Existing note review

- [原辅助入口](../../implemented/feature/2026-10-26-trae-official-custom-models.md)：扩展发行版范围，原国际版的身份和路径隔离仍保留。本篇替代“仅国际版”限制，不替代人工配置的边界。
- [完整接入提案](../../proposed/feature/2026-10-26-trae-native-integration.md)：仍有自动化和取消验收缺口；国内版可安装不能证明这些能力。
- [实验发布](../../proposed/feature/2026-10-27-agent-experimental-release.md)：本轮只做本地修改，发布门槛仍由该篇保留。

## Alternatives considered

- 把两个App名称放在同一自动发现列表：代码最少，但同时安装时会隐式选择另一版，手选路径和下载观察也无法说明目标，不采用。
- 删除国际版、统一换成国内版：国内用户流程简单，但会破坏已有国际版选择和测试记录，不采用。
- 共享向导并分离版本目标：增加一个显式选择和独立路径键，换取目标、官方来源和签名一一对应，采用。

## Consequences

国内版3.4.9/build2.3.97430的Apple公证、签名与首次引导已验证，身份cn.trae.app/CG2SCM6AV5。用户可明确选择发行版，避免国内版安装被误判缺失或启动另一版；代价是需要维护两套身份与协议证据，路径选择额外增加一个目标。旧Chat Completions的none参数错误由独立Responses配置避开，原生通过范围以上述新笔记为准。官方未来签名变化须重新核验，不模糊接受任意签名。不同平台仍需对应平台验证，不因本机成功扩展到Windows。用户已授权修好后推送、合并与发布，最终发布仍需检查Accio和共同代码的剩余门槛，不覆盖用户正在运行的元衡安装包。
