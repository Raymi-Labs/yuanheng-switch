# Agent Note: Codex 原生插件管理与隔离验证

Status: implemented

## Problem

用户要求一次性在本地完成兼容插件接入。现有Skills/MCP有各自安装与同步，但commands/plugin只处理Claude配置，无法管理Codex插件包。安装与加载、外部授权、实际执行不能混为一个成功状态。

## Decision

以602c4c78主线为基线，能力中心增加Codex插件区，复用当前目标与现有Skills/MCP导航。原生app-server作为协议Adapter，固定允许initialize、plugin/list/read/install/uninstall、config/read/value/write、skills/list；不发turn/start或模型请求，不做CDP注入或第三方源码移植。

内置两个MIT自有插件（代码审查Skill、官方公开文档MCP与Skill），以及用户选择本地目录导入。扫描、内容摘要和配置摘要生成安装计划；确认后复制为不可变来源快照，独立市场名由内容摘要生成；不克隆任意仓库、不下载解压第三方包、不运行安装脚本。Skills与MCP原生插件组件由Codex管理，不另写统一Skills/MCP数据库。

所有管理操作显式绑定目标Codex home与引擎；原生目录/配置写入不碰模型、账号、auth.json。增量修改插件enabled通过原生config接口并校验版本。只管理本客户端注册的来源，配置归属/来源变化时拒绝操作；不接管原有官方/用户插件。操作互斥、原生子进程限时/限输出/结束回收；操作先写pending，未知结果由刷新核对，不自动重试安装。

插件扫描拒绝链接、路径逃逸、特殊文件、敏感配置文件与无效manifest；导入支持当前原生兼容格式与portable格式，不删除脚本伪装安全，含代码/钩子/网络能力在安装前显示风险，hooks保持原生信任机制。加载检测只报告独立原生引擎发现证据，GUI会话与业务调用尚需新聊天确认，不宣称MCP授权和业务调用通过。

## Alternatives considered

复制CodexPlusPlus或先注入页面：官方已有原生接口且CLI/桌面引擎隔离探针通过，无需引入AGPL源码及页面耦合。

直接改写config整文件或手工写插件缓存：容易覆盖伙伴模型和用户配置；复用原生安装与配置接口，并检查计划/归属漂移。

先做完整远程社区市场：扩大授权、下载和来源供应链范围；本地导入及自有样本足以交付可用原生闭环，远程目录留明确后续范围。

## Verification

隔离CODEX_HOME验证原生插件安装、列表、skills发现、停用/启用、卸载与重装；无真实认证、无收费请求。恶意路径/链接/敏感文件、计划内容变化、配置变化、切目标迟到响应、未知操作、原生失败不泄露正文回归。前端测试/类型/构建、Rust测试/Clippy、笔记检查与界面检查；遗留工作进程为零。

## Consequences

本地程序与MCP由Codex按其权限运行，不声称沙箱。官方云OAuth受原生账号能力限制；不能绕过。不同Codex版本可能协议不兼容，明确报错不回退写缓存。当前Mac可测，Windows/Intel运行需单独验收。已有生态总体方案仍为路线图，本批仅落地Codex本地插件闭环。

## Sources

官方：https://learn.chatgpt.com/docs/plugins?surface=app；https://developers.openai.com/plugins/build/plugins。本机codex-cli 0.167.0、桌面内置引擎0.166.0-alpha.5.1隔离探针：本地市场安装与skills/list发现成功。官方明确API key支持部分插件而非所有OAuth。未引用第三方代码。


## 实际验证与剩余范围

前端182文件1359项通过，含原有能力中心回归；类型检查及renderer构建通过。原生包与协议测试覆盖路径逃逸、链接、凭据文件、内容/市场篡改、已安装用户改动保护、portable兼容清单、脚本权限保持、原生错误脱敏、拒绝自动审批及超时子进程回收。桌面内置引擎隔离安装全流程通过，合成MCP实际ping通过，无模型请求、无真实登录文件。

安装计划仍是10分钟单次token，操作前复核文件摘要；原生配置使用语义版本CAS。初始CAS测试仅改注释未触发版本拒绝，改为真实配置字段后验证拒绝并保留修改。新增面板与原有图像卡片曾使用相同React key，定向回归发现后改为独立key。Mac临时目录含系统/var软链接，测试目录canonicalize后再检验，未放开包内软链接。界面首轮弹窗主体缺间距，已补齐并复看。

本次为现有能力中心扩展，遵从用户既定简洁交互，不另建视觉系统或新增侧栏。五语言文案沿用desktopI18n；impeccable检测无问题。浏览器实际面板配合合成IPC完成安装确认、域名/程序后果提示、加载检测、停用与卸载确认，600×800暗色无横向溢出；不将模拟外壳称作完整Tauri真机验收。

原生插件不绑定元衡账号，因为插件属于用户的Codex配置目录，不含元衡凭据；CLI和桌面若共用该目录，状态也共用。外部授权由Codex处理。首期不支持远程仓库下载、自动更新、多Agent原生插件或所有云OAuth，用户导入新版本为独立身份，需要主动停用旧版本。未知安装失败可以刷新或明确卸载，不能自动重放。


最终原生12项安全/恢复/进程回归通过；另显式运行桌面引擎和CLI的原生安装全流程各1项通过，合成MCP调用脚本复验通过。进程测试使用短时限验证父子进程退出，所有真实凭据与模型请求均未使用。配置CAS同时从origins和layers取得用户层版本，无法确认版本时拒绝覆盖。管理根目录Unix权限700。来源与安装副本都被修改时拒绝删除，以免误删用户改动，需在原生Codex核对。

此批没有完成真实账号的第三方API模型自动选择插件、GUI聊天重载、OAuth服务和Windows/Intel原生执行，必须保留上述验收边界。共享Skills/MCP只复用入口与原有能力，本次没有把它们强行迁移成另一份数据库状态。
