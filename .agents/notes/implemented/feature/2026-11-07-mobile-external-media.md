# Agent Note: 外部安卓媒体改版的安全移植

Status: implemented

## Problem

用户提交20261106安卓源码与APK，要求审查并创建PR。来源基于旧版，新增语音克隆、多参考图、遮罩编辑和广场刷新，同时缺失当前账号隔离、钱包发起账号、兑换幂等和iOS限制。不能整体替换当前mobile。

## Decision

以最新main为基线，移植新增媒体功能，复用当前会话、取消、同意、账号绑定收藏和并发控制；保留名称、版本号、正式签名、兑换和iOS边界。外部APK与生成的tauri目录不提交、不执行，PR先保持草稿，真实语音权限与Android触摸/相册需要后续验收。

不采用外部公共gallery目录和无账号参数命令；参考图与遮罩随收藏原子落盘且受现有总容量约束。模型广场仅吸收带登录态查询与回前台刷新，保留当前分组筛选和余额单位，不用正则推导任意计费表达式。声音功能采用外部布局与MiMo协议，额外保证切号/卸载取消、授权确认、样本竞态及内存限制。

## Existing note review

- [伙伴改版](../../implemented/feature/2026-11-01-mobile-partner-integration.md)：扩展媒体，不推翻账号/幂等修复。
- [移动架构](../../implemented/architecture/2026-10-19-mobile-clients.md)：沿用固定HTTPS域名与原生会话，独立于桌面Core。

## Alternatives considered

- 直接覆盖压缩包：完整但回退安全修复和版本签名，拒绝。
- 仅提交截图或复制源码到旁路目录：可留档但不能评审真实产品增量，不采用。
- 基于main移植实质新增项并保留草稿验收边界：避免旧安全逻辑回流，采用。

## Verification

现有安全回归继续通过；新增媒体输入限额、取消/卸载、账号绑定及遮罩约束测试通过；无收费调用，不宣称APK真机或签名覆盖更新已通过；遗留测试进程零。

移植后的前端测试覆盖授权、仅一次提交、卸载取消、晚到音频样本、多图转发、账号绑定收藏和超大画布拒绝；Rust追加音频/指令限制、参考图/遮罩组合验证和账号收藏往返。现有安全测试全部保留，没有用外部旧测试覆盖。首次拆分MaskEditor遗漏画笔常量和未用import，类型检查发现后修复；Rust离线依赖缺失后按锁文件补齐，未修改依赖版本。

本地44项移动前端、18项Rust回归通过，TypeScript/Vite生产构建与Rust Clippy通过。笔记包装入口缺Bun，使用Node执行相同三份检查器通过。保留单图请求的image字段，多图使用image[]；现有兑换测试有React act警告但断言通过，不作为原生操作证据。仅提交草稿PR，不合并发布；任务结束检查测试进程归零。

声音实现经关联服务端源码复核，改为已有登录态`/pg/chat/completions`，服务端负责分组访问检查；不再使用外部生图临时令牌。基于合成测试验证，线上音频请求和Android真机尚未验收。源APK证书与正式证书不同，不安装、不分发，仅记录公开摘要；完整取舍见[审查报告](../../../../docs/reviews/2026-11-07-mobile-external-review.md)。

## Consequences

后续浏览器验收发现打包CSP只有default-src self，声音页data音频会被阻止。仅增加media-src self/data/blob，保留脚本和网络连接约束，不关闭CSP或开放任意远端音频；AI数据处理说明补声音/遮罩，声音标题改为直接的“声音克隆”，去掉标语和重复说明。新增实际Chromium生产renderer测试，IPC/账号/媒体均合成，使用配置原文作为HTTP CSP。旧策略复现media-src拒绝，新策略样本/结果加载且play成功；200×100遮罩中心alpha=0、角落255；320/390像素宽六入口无横向溢出。修正测试等待页面动画与稳定点击，不通过禁用动画或放宽断言掩盖结果。外部请求0、没有真实模型或个人数据。

最新本地48项前端测试、类型/生产构建、真实浏览器验收通过；旧提交fa6972c4的Android/iOS及全部CI已通过，本次新SHA需重新跑。测试脚本finally退出浏览器并关闭本地HTTP服务；无测试遗留进程。不具备Android SDK/adb，本轮不宣称原生设备验收。取舍为保留最小本地媒体权限而非改用远端音频URL或放宽默认CSP。可重复入口见mobile/scripts/test-media-browser.cjs。

PR后续审查：8fc6ba45的GitHub移动checks、Android、iOS以及桌面三平台CI均通过。随后补声音替换时清空旧样本/授权、空音频拒绝和过期读取错误抑制，避免新样本读取中误提交旧内容。遮罩增加解码就绪检查、轻点实心笔迹、单指归属/捕获丢失清理、导出异常提示；不修改模型数量限制。最终46项前端测试、类型与Vite构建通过；新回归是合成DOM/Canvas桩，不能代替Android画布像素和触摸真机验证。18项原生回归来自此前未改变的Rust代码。原有兑换测试act警告仍保留。补充提交需重新看CI，不套用旧SHA的通过结论。

声音模型权限及格式仍需线上验收，不能伪称已接通；支持遮罩的模型和图像维度限制依赖上游。参考图随收藏JSON保存，受既有64MiB单条和80MiB合计限额，过大时明确失败，不拆文件绕过限额。附件作者身份未知，不猜测署名；原APK仅作为来源证据。PR保留草稿，版本和发布流程不变。
