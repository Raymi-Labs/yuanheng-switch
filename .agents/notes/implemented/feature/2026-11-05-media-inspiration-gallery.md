# Agent Note: 图片与视频灵感入口

Status: implemented

## Problem

用户希望参考大图模型展示页，让客户端已有生图能力更有吸引力。当前MediaStudioPage进入即参数表单，缺乏可理解的创作示例。现有账号目录、草稿、提交、预览、保存及历史必须复用，不能造第二条收费路径。

## Decision

配图和布局部分已由[作品图改版](2026-11-05-media-gallery-artwork-redesign.md)取代；以下SVG和Muse示例验证为首版记录，账号、草稿和提交边界仍沿用。

同一MediaStudioContent内增加灵感广场、创作工作台和我的作品视图；只切可见性、不卸载控制器，保留草稿与视频轮询。原创本地SVG插画作为灵感配图，明确不是模型实测结果，不复制竞品素材或品牌，不请求外部图片。静态模板仅含推荐模型和提示词；卡片查看详情可浏览，使用时按当前账号目录精确匹配模型，不静默换型号或自动提交。已有描述/参考图需确认替换，取消保留；读取/生成/作品处理及目录刷新期间禁用套用，切号重置。

现有能力：侧栏→MediaStudioPage→账号模型目录/历史→原生media_studio权限与提交校验；作品转视频仍复用既有草稿准备；不改API、计费、原生下载边界或50条历史限制。关联[创作页](../../implemented/feature/2026-10-31-media-studio.md)、[图片转视频](../../implemented/feature/2026-10-31-image-to-video-workflow.md)。

## Alternatives considered

- 只在表单上方加宣传图片：改动最少，但页面冗长、创作与浏览混杂；选择同页三个视图，现有任务状态仍留在同一控制器。
- 新独立广场后端/用户公开作品：有社区扩展潜力，但本次不需要上传私人作品或新服务。
- 远程图库或竞品图片：可快速取得照片，但增加外部联网、来源和授权问题；本版使用原创代码插画并标注示意，不假装模型产物。

## Verification

完整前端173文件1288项通过；定向媒体49项通过，新增素材/翻译5项并纳入全量。覆盖模型权限和目录失败、模板取消保留草稿/参考图、填充不提交、明确生成后请求模型正确、Muse草稿时长默认、提交时拒绝套用、切号丢弃旧结果，原有轮询/保存/多图回归保持。TypeScript和生产renderer通过；保留原有大chunk及浏览器数据旧版本提示。

使用真实MediaStudioPage组件配合本地模拟IPC做浏览器验收，不连接真实账号，submit明确拒绝。1440×1000、900×650和600×800检查无横向溢出且图片全部加载；浅/暗主题、详情/Escape关闭和Sunburst带入草稿实际观察通过。预览外壳侧栏是模拟环境，不冒充正式Tauri安装包。首次预览缺react-refresh解析路径，修正隔离预览依赖后通过；建筑SVG弧线初版坐标错误已修正并重看截图。旧切号测试因默认入口变更需要先打开工作台，仍保留原隔离断言。

所有素材为本轮原创向量图，不是收费生成或命名模型出图。使用说明、能力地图和素材来源说明同步；本轮不推送、不发布。

## Consequences

插画仅是风格指引，不保证各模型输出一致；后续如替换为真实样张须另有生成授权与来源记录。本轮仅本地实现，不推送、不发布，不收费生成。

作品记录在独立视图与工作台底部共用，避免旧流程额外跳转；同一控制器不因视图切换重建，视频等待状态仍可见。导航支持方向键/Home/End，套用草稿后聚焦描述框。

最终格式和93篇笔记门禁通过；浏览器方向键/Home切换及套用后描述框焦点、滚动归顶已实际验证。临时预览页关闭、窗口尺寸恢复，预览服务收到SIGTERM退出，监听端口已释放；本轮遗留测试/构建/预览进程为零。
