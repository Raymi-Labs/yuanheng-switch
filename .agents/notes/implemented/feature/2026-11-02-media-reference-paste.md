# Agent Note: 创作参考图支持主动粘贴

Status: implemented

GPT Image参考图数量、格式及文件大小由[官方多图适配](2026-11-02-gpt-image-multiple-references.md)部分取代：支持最多16图及WebP，每张小于50MB；粘贴追加，切换较小容量型号保留草稿并要求调整。此前GPT单图限制为历史实现，其他能力边界不变。

## Problem

用户复制图片或截图后还需要另存文件再上传，增加参考图操作步骤。现有创作页已经拥有参考图读取、预览、限额、排序、模型切换及原生提交校验。

## Decision

在图片与视频创作表单接收用户主动触发的paste事件，提取剪贴板图片文件并复用上传的pick路径；只含文字时不拦截原生粘贴。无图片文件的URL/HTML不下载、不转换；不监听全局剪贴板，不新增系统权限。图片进入草稿，仍须明确点击生成才发送。单图型号替换原图，Muse追加，沿用1/4张、10MB单张/24MB总量及格式限制。读取、提交或作品处理期间不接受新图片；同步读取锁防止连续粘贴破坏已有异步读取，切号/卸载/切模型使旧结果失效。

影响入口仅创作表单、参考图提示与翻译；IPC、原生真实解码、账号隔离及计费提交不变。复用[参考图流程](../../implemented/feature/2026-10-31-image-to-video-workflow.md)和[Muse多图约束](../../implemented/feature/2026-10-31-muse-long-multireference.md)。

## Alternatives considered

- 仅保留文件选择：无需变更，但复制截图仍需另存文件，不能解决反馈。
- 主动读取系统剪贴板按钮或原生插件：可提供额外入口，但带来权限和跨平台维护，本次使用已有WebView paste文件事件。
- 从HTML/链接自动抓图：覆盖更多网页，但会触发非预期联网且需额外下载信任边界；仅接受剪贴板实际图片。

## Verification

媒体页30项（含8项新增粘贴场景）及保存契约5项，共35项通过。覆盖图片只进草稿、明确生成才提交、单图替换、Muse有序追加及files/items不重复、数量/格式/体积拒绝、失败保留原图、纯文本/HTML不拦截、连续粘贴与读取失败恢复、提交期间拒绝、切模型和切账号丢弃旧结果。首次两项测试因下拉框选择器歧义失败，限定“生成模型”标签后通过；产品逻辑未为测试放宽。TypeScript及生产renderer构建通过，五语言提示已补齐。未调用真实生成API、未读取本机实际剪贴板或账号凭据。

## Consequences

浏览器或来源应用可能只把URL/HTML写入剪贴板，此时仍需复制图片本身或使用文件选择。自动化组件测试不能替代各平台原生WebView粘贴验收。
