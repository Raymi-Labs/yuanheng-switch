# Agent Note: 账号目录声明推理档位

Status: implemented

## Problem

模型列表动态更新，但托管目录及工作台使用内置档位，新型号需要重新发版。

## Decision

扩展[托管目录迁移](../../implemented/bug-fix/2026-11-16-managed-reasoning-catalog.md)：在既有账号模型响应上读取精确型号的显式声明，按账号缓存，工作台、配置验证和原生目录共用。模型能力与工具支持的交集不是用户选择；不调整显式选择或路由。

## Alternatives considered

增加更多前缀规则省去后台配置，却可能给接近的型号错误开放高档。独立请求增加一次失败机会，复用目录响应可沿用可见性边界。

## Verification

Rust 隔离测试将合成新型号从平台 JSON 经账号会话、工作台和 Agent 交集，写入临时 Codex 原生目录并读回；覆盖清空、错账号/站点、其他组、坏行、手工目录、撤销后的选择及桥接会话覆盖。React 测试覆盖同型号过期档位不静默重置。未调用上游模型。

## Consequences

声明缺失时保留旧能力规则；已确认的 gpt-6.2-astra/sol 离线有六档，默认 medium。无元数据的响应仅可复用同源同账号快照，权威空表撤销声明，坏行隔离处理。启动、账号刷新或凭据修复可更新受托管的 Codex 目录；只有同组明确可用的新声明才能追加，不删除用户模型或改分组。其他写入原生目录的工具使用现有更新入口，不后台重写其文件。旧客户端和全新协议档位仍需升级。同步不代表原生应用已重载，更不代表各渠道实测。
