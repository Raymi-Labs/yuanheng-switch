# Agent Note: 公告铃铛与就近工具选择

Status: implemented

## Problem

工作台两条公告横幅长期占据首屏，即使已读或没有平台公告仍保留空间。工具选择位于远处的灰色顶栏按钮，和当前工具的操作区域脱离；快捷切换标题及说明重复占位。

## Existing capabilities and impact

复用 PlatformAnnouncementCenter 的全局公告窗口、两版更新缓存、平台定时同步及本地已读标记，将两个横幅迁为 App 工具栏铃铛。复用 App 的 activeTool、可见工具过滤与持久化，WorkspaceDashboard 传递至 FocusToolCard，采用既有 CompactSelectPicker。

[工作台统一操作](../../implemented/simplification/2026-10-12-workspace-single-tool-controls.md)部分重叠：单个焦点卡原则继续成立，工具入口从顶栏移入卡片，两篇互链。[顶部更新入口](../../implemented/feature/2026-10-12-top-row-update-entry.md)属于安装更新动作，保留其登录外可用、忽略后仍可手动升级的决定；本次铃铛承接公告阅读。帮助抽屉、安装监督与连接诊断不属于本次改动。

## Decision

铃铛保持可见，有任一分类未读时显示红点，打开未读分类；阅读一个分类不清除另一个分类红点。分类页签显示各自红点，沿用有界本地标记；公告内容变化重新提醒。网络失败在公告窗口呈现，工作台不展示占位横幅。窗口关闭后返回触发按钮。

当前工具标题下放置明显可点击的下拉框，加载、检测失败和所选工具未安装时同样提供切换；保持原工具集合及配置/启动语义。删除快捷切换标题和说明，保留模型、分组及官方账号提示。

## Alternatives considered

- 横幅提供关闭：实现最少，但有新公告仍挤占首屏，已关闭后也需要可发现的历史入口；采用单个持久铃铛。
- 两个铃铛：分类直达清晰，但增加重复按钮；沿用一个公告中心和分类红点。
- 仅提高顶栏工具选择对比度：不改变布局，却不能缩短选择与当前工具操作的距离；将选择移到卡内。

## Verification

144 个前端测试文件、922 项测试通过，包含公告分类独立已读、刷新恢复、内容变化再次提醒、离线缓存与存储不可用；当前工具加载/失败/未安装切换、三种桌面工具刷新恢复及原配置与启动路径通过。类型、前端格式、renderer 构建、版本公告一致性与差异检查通过；renderer 仅有既有体积提醒。

真实 App 壳以隔离模拟 IPC 验收 1280×900 浅色与 900×600 深色布局、鼠标与方向键打开工具选择、切换未安装 DSH 再返回、刷新保留选择、两类公告分别阅读与红点消除、关闭/Escape 焦点恢复、阅读后刷新仍无红点。初次自动化在弹窗动画完成前发送 Escape，等待弹层完成挂载后重跑通过；没有为验收修改产品时序。浏览器模拟未调用真实安装、模型或工具启动，原生包由发布流程校验。

## Consequences

工作台首屏释放两条横幅空间，工具选择与操作就近。单个铃铛仍可查看历史，分类未读互不影响，跨窗口 storage 事件同步标记；平台正文/附注/类型变化会重新提醒。明确标记本机已读，禁用存储时仅当前挂载会话记住。安装更新按钮、账号、工具配置写入时机与接口不变。当前工具选择从顶栏迁出，其他工具维护由工具管理承接。
