# Agent Note: Claude Desktop 首次运行环境准备

Status: implemented

## Problem

新用户安装应用并写入网关配置后，才在 Claude 中看到 Virtual Machine Platform 缺失。已有诊断只报告状态，不拥有安装前准备、UAC、重启及恢复流程，导致反复手工操作。

## Existing capabilities and impact

复用桌面下载/监测 hook、配置与启动 API、工作台应用容器和现有 Windows 环境探测。新增受控的系统组件准备 IPC 和共享状态入口，不把 CLI 安装监督的 Job 强杀用于 DISM 系统功能安装。

活跃笔记：Claude 诊断与后台日志笔记部分重叠，本轮将只读环境检查扩展为用户授权的准备入口，原不自动收费、不修改网络规则仍成立；安装等待笔记拥有外部下载观察，保持其 AbortController 和超时；Windows CLI 安装脚本校验不涉及 Claude Desktop 的系统功能。模型分组笔记无关。保留全部已有未提交工作。

## Decision

- 单次“安装并准备”意图包含检查并启用必要的 VirtualMachinePlatform；启动/配置已有桌面应用也复用同一入口。只启用确认必要的功能，不凭“全部同意”修改 BIOS、代理、防火墙或回环规则。
- UAC 使用 Windows 原生提权，仅运行系统目录的 DISM 和固定参数；不下载提权脚本、不接受任意程序/参数、不强杀系统安装进程。
- 共享状态显示检查、等待管理员批准、准备中、需要重启、未知、失败、基础环境就绪。重复点击复用同一任务；UI 退出不伪装取消系统安装。
- 写入不含账号、密钥的重启恢复标记，默认在重启后只读复查并给出继续入口；用户可通过[提醒偏好](2026-10-13-claude-preparation-reminder.md)关闭自动提醒，主动操作仍检查环境。不自动重启、不在启动时自动提权，不把可能收费的模型测试加入流程。
- 已配置用户通过原事务保存模型/分组后准备环境；准备延期使用 `ClaudeWorkspaceDeferredError` 区分于配置失败，刷新状态但不回退已保存选择。恢复入口只使用当前账号下已保存配置，不重放旧账号的内存操作。安装观察停止后，迟到的准备结果不会打开下载页。
- 功能启用与工作区下载、模型连接分别说明，不能显示全部已可用。下载沿用官方页面和 Claude 自身组件准备；网络下载失败不伪装成系统功能未启用。

## Alternatives considered

- 继续要求用户执行管理员命令，修改最少，但无法满足首次安装闭环；引导必须进入现有一键流程。
- 自动强制重启或给整个客户端管理员身份可减少按钮，但会中断用户工作并放大权限；仅 DISM 子进程提权，重启由用户保存工作后主动执行。
- 全量安装 Hyper-V/WSL/Node 并调整防火墙容易过度修改；仅准备已确认的必需组件，未知硬件/系统限制明确提示。

## Verification

- macOS 上当前工作区 Rust 回归 2451 项通过、2 项原有忽略；Clippy 无警告、前端 TypeScript 与 852 项测试通过，renderer 构建通过。包含已有其它未提交改动，不把它们声明为本功能独有工作。
- 新增状态测试覆盖：同次启动/重启后确认、结果未知、系统服务缺失、管理员拒绝、DISM 非零/3010、未明确确认拒绝准备，以及非 Windows 不操作。
- 前端反例覆盖：跨调用共享任务、拒绝授权不调用系统修改命令、重启标记无账号/密钥、十分钟界面等待结束但不杀 DISM、取消安装观察后迟到结果不打开网页、其它桌面工具跳过准备。
- 独立 Chrome + 模拟 IPC 实际操作准备、重启提示、收起/重新打开、基础环境就绪和继续，准备命令仅调用一次；1100px/390px 布局不溢出，测试浏览器/服务已关闭。
- Windows 专用 Rust 使用 x86_64-pc-windows-msvc 隔离 harness 类型检查通过；移除的仅是 Tauri 导出宏，配置存储为 stub，保留实际原生 ShellExecuteExW/COM/进程句柄调用。不是完整 Windows 客户端构建或实际 UAC/系统安装验收。
- 代码未进行系统组件安装、收费请求、推送或发布；Windows 真机 UAC、DISM、重启及官方工作区下载由用户后续验收。

## Consequences

系统安装不能安全强杀；超时后保持“结果未确认”并禁止重复提交，重启或系统状态确认后再继续。固件虚拟化和官方下载可达性不由元衡绕过。必须将基础就绪与完整推理成功分开。

配置前/启动前环境查询新增有限等待，基础查询最长八秒；管理员授权窗口属于用户交互，不伪装可取消。客户端关闭不杀系统安装，若无法取得或恢复子进程结果，启动标记保守要求人工确认系统窗口结束再重启，不重复提权。即使 DISM 返回 0，也先要求一次重启后再用新启动时间和实际状态确认，代价是部分本可即时生效的机器也会多一次明确重启步骤。

说明与真机清单见 [首次准备](../../../../docs/guides/claude-windows-first-run.md)。原安装响应校验、安装等待、模型选择改动保留；本轮不发布。决策笔记校验不替代 Windows 行为验证。
