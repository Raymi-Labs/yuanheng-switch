# Agent Note: 灵感广场作品图与轻量布局

Status: implemented

## Problem

首版SVG示意和大标题未达到用户期望的作品展示效果。用户提供三张高分辨率PNG，要求在同步伙伴更新后本地接入，不能把静态图片宣传为视频样片或指定模型实测结果。

## Decision

复用[原入口决定](../../implemented/feature/2026-11-05-media-inspiration-gallery.md)的账号目录、草稿确认和提交边界；替换为用户提供的花园、极光、山谷图片。仅打包去除元数据的缩小WebP，原文件保持不变。横图左侧堆叠、竖图右侧完整展示，窄容器单列；移除图片遮罩和大标题，标签放到图片外。

三张均为图片灵感；移除旧SVG视频卡，视频筛选显示明确空态和工作台入口，不伪造视频样片。推荐模型只是草稿目标，不代表素材来源，匹配现有授权目录，不自动降级或付费提交。

## Alternatives considered

直接打包42MB原PNG会增加安装包和解码成本，页面展示无需4K原图；保留用户原件并打包适配尺寸WebP。

沿用旧SVG或将极光图伪装为视频卡不能满足视觉目标与真实性边界；保留视频生成能力但不展示虚构视频样片。

另建创作控制器会重复账号、草稿和提交状态；仅扩展现有页面。
