# Agent Note: Claude 环境准备可关闭启动提醒

Status: implemented

## Problem

Claude Desktop 环境准备失败后，前端保留 pending 标记；“稍后处理”只关闭本次弹窗，每次进入元衡又显示准备提示，无法选择不再提醒。

## Existing capabilities and impact

复用 `claudeWorkspaceSetup` 的共享状态、现有本地恢复标记和 `ClaudeWorkspacePreparation` 弹窗；安装、配置、启动都经共享环境检查，Rust 启动入口仍会复查。新增偏好只涉及本机提示，不需要新的后端接口或系统配置。

检索结果：[首次环境准备](2026-10-02-claude-windows-preparation.md)部分重叠，本笔记扩展其默认恢复提醒；安装响应校验、诊断和下载观察笔记不涉及提示偏好，保持原决定。

## Decision

在环境状态说明下提供“不再提醒”复选框，勾选即时持久化本机偏好，关闭弹窗后不再展示闲置恢复按钮，后续启动也不自动检查或打开提示。保留 pending 标记与后端准备状态，主动安装、配置、启动仍检查并展示必要错误，且不清除用户的提醒偏好。主动进入该弹窗可取消勾选恢复提醒。存储写入失败时保持原值并在复选框旁提示失败。

## Alternatives considered

- 直接删除 pending 标记：改动少，但主动重试又会写回，无法表达长期不再提醒，且混淆任务恢复状态和展示偏好。
- 跳过整个环境检查：可以完全不出现相关提示，但会让主动安装或启动绕过必要条件，无法正确报告真实准备结果。

## Verification

- 前端 144 个文件、918 项测试通过；类型检查、renderer 构建、改动文件 Prettier、版本一致性及笔记校验通过。构建仅有既有包体积及浏览器数据时效提醒。
- 新增回归覆盖失败、未知、取消、固件限制、缺组件和待重启的复选框；完整模块重新加载保留偏好；手动失败/成功都不清除偏好；取消勾选恢复提醒；损坏和不可写存储不伪装保存成功。原有安装、授权及系统准备边界回归通过。
- Playwright 在完整应用壳、模拟 Windows IPC 下验证 1100px 浅色与 390px 深色：勾选/关闭/刷新后无弹窗、无环境检查；工具管理主动配置仍检查并显示失败，原勾选保持；无系统修改调用。截图保留在本机 `output/playwright/claude-reminder-*.png`。

## Consequences

失败用户可继续使用元衡其他工具，默认恢复流程仍保留。偏好跟随本机客户端存储，不随账号或其他设备同步；清理本地存储会恢复默认提醒。显示偏好不会移除后端任务状态或取消运行中的 DISM；收起后运行中的任务仍保留返回入口，结束后不再显示闲置入口。

浏览器模拟验证不能证明 Windows UAC、DISM 或用户机器安装成功；安装包构建与发布结果需以既有 Release 工作流为准。
