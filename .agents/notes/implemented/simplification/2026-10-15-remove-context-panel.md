# Agent Note: 移除重复状态面板并明确语言入口

Status: implemented

## Problem

工具栏“当前状态”按钮的用途不明显，打开的内容与账户、工作台、用量和连接页面重复；宽窗口还自动占用右侧 272px。用户要求移除按钮及功能，并将语言入口改成明确的翻译图标。

## Existing capabilities and impact

App 挂载窄窗口 ContextPanelDialog 和宽窗口 DesktopContextPanel，二者没有独立设置或持久化偏好。余额仍由 DesktopSidebar 展示，当前工具由 FocusToolCard 承载，用量和连接状态各有主导航页面。只删除重复展示及其查询订阅，保留共享 API 和数据。

检索现有笔记后，公告与工具选择、帮助抽屉、顶部更新入口均属于相邻工具栏功能，其决定继续成立；没有现有笔记拥有 ContextPanel 的保留理由。LanguageSwitcher 已有五种语言、保存失败回退和无障碍名称，复用其流程与 lucide-react 图标。

## Decision

移除 App 中的按钮、状态、两种面板挂载及专用组件，清理只属于该入口的五语言文案和既有测试断言。所有窗口宽度统一由主内容区占满剩余宽度。语言按钮改为 Languages 文/A 图标，配浅色圆形底和清晰前景色，保持原菜单、保存与回退逻辑。

## Alternatives considered

- 只隐藏顶部按钮：改动最少，但宽屏仍会出现用户要求移除的功能并占据空间，因此删除两种展示。
- 用自绘图片精确复刻参考图标：可控制每条线条，但增加资源维护和主题适配；已有 Languages 图标表达同样语义，沿用项目 SVG 图标体系。

## Verification

144 个前端测试文件、923 项测试通过，类型、格式、renderer 构建与版本公告一致性检查通过；构建只有既有包体积提醒。清理已移除入口对应的既有本地化断言，不为图标样式增加重复单测。

真实 App 壳使用隔离模拟 IPC，验收 1440×900 与 900×600 的深浅色组合：只保留左侧导航，主内容右边缘抵达窗口，无水平溢出；语言菜单五种选项可见，键盘打开/Escape 焦点恢复、中英切换和刷新保持、保存失败回退均通过。帮助抽屉及设置入口正常。初次验收的帮助焦点断言早于关闭动画后的恢复，等待实际焦点后通过，没有修改产品时序。

## Consequences

用户无法在右侧同时速览统计，需要进入已有用量或连接页面；若以后出现必须边操作边监控的独立场景，应重新评估具体工作流，不恢复重复全局面板。浏览器模拟只验证交互布局，原生包仍由既有三平台发布流程核验。
