# Agent Note: 工作台统一到当前工具操作

Status: implemented

## Problem

工作台同时显示当前工具卡片与快捷控制台，重复呈现模型、分组、启动操作；工具管理又提供全部工具维护。首页纵向列表过长，让日常操作缺少明确入口。

## Existing capabilities and impact

[WorkspaceDashboard](../../../../src/components/desktop/WorkspaceDashboard.tsx) 同时挂载两个控件并共享 useModelSwitchCenter；[App](../../../../src/App.tsx) 顶栏已有持久化工具选择。[FocusToolCard](../../../../src/components/desktop/FocusToolCard.tsx) 已支持模型、分组、启动目录、Codex 账号方式与启动；推理等级、Codex 终端应用状态和快照过期提示需要从快捷控制台迁入。安装、路径选择、维护继续由 ToolSetupGrid 提供，不改变后端命令或配置写入时机。

现有[收藏笔记](../../implemented/feature/2026-10-04-model-picker-favorites.md)部分重叠，更新入口数量而保留收藏与权限决定；安装监督、DSH 安装、顶部更新、钥匙串相关笔记不涉及本次首页布局决定，保留独立归属。

## Decision

移除 ModelSwitchCenter 展示组件，保留 useModelSwitchCenter 状态与现有操作链。当前工具卡承接支持工具/模型的推理等级选择、手动重新检测、旧快照提示与 Codex 终端应用状态；官方账号模式继续隐藏元衡选择器。空状态也能重新检测。账号用量与当前工具并排展示，下方依次展示今日统计和智能体检。能力中心与工具管理使用左侧既有导航，工作台不再显示重复导航卡或为其读取技能、MCP、已配置工具数量。健康卡复用原有检查、修复、详情和配置/连接回调，消除重复入口占用的空间。

## Alternatives considered

- 折叠快捷控制台：保留一次查看所有工具的便利，但展开后仍存在重复操作与两套展示维护，因此选择用既有工具管理承载多工具场景。
- 删除当前工具卡、保留列表：多工具操作路径短，但失去围绕顶栏所选工具的清晰焦点与启动目录入口，不符合精简日常首页的目标。

## Verification

143 个前端文件、900 项测试通过；最终布局和版本修改后，App、焦点卡及公告回归再次通过。类型、格式、renderer 构建与版本一致性检查通过，构建只有既有包体积提醒。焦点卡和 App 回归覆盖分组收藏不提交配置、明确选择后应用分组/推理、工作目录启动、Codex 待应用信息、官方账号模式、空状态跳转/重试和刷新互斥。

真实应用壳在独立浏览器中使用模拟 IPC 验收：1280×900 明暗主题、900×600 最小窗口、顶栏切换与刷新保留、推理选择调用原配置接口、首次检测失败重试恢复、后台检测失败保留旧快照、无工具跳转管理、页面切换、加载及未登录边界。临时预览初次因启动目录 mock 返回类型错误而失败，修正 mock 后重新验收；应用未为测试放宽返回值契约。模拟验收不涉及真实账号、安装或付费模型请求，不代替原生工具端到端运行验证。

体检下移与重复导航清理通过 144 个文件、922 项测试，以及类型、格式、构建、版本和笔记校验；移除的 1 项旧测试只校验已删除卡片的数量文案。真实应用壳使用模拟 IPC 验收 980×900、900×600、1440×900 深浅色：体检与统计带同宽且位于其下方、无水平溢出，侧栏两个入口各保留一次并可跳转，刷新和详情展开/收起正常；取消修复不提交配置，体检成功、失败、错误和配置引导状态均可操作。

## Consequences

首页只保留一个当前工具操作区，删除 542 行重复展示代码。首页不再同时列出全部工具；通过顶栏切换或工具管理操作其他工具。后端命令、收藏权限、模型目录与配置写入时机不变。若出现明确的多工具并行操作需求，优先在工具管理扩展，不恢复重复首页控制列表。

## 入口后续调整

[公告铃铛与就近工具选择](../feature/2026-10-13-workspace-notifications-tool-picker.md)将顶栏工具选择迁入当前工具卡，覆盖加载、失败和未安装状态；本篇的单个工作台操作区决定继续成立。原验证记录中的顶栏选择对应当时入口。

[Codex 配置标记恢复](../bug-fix/2026-10-14-codex-surface-mode-repair.md)修正首次单工具配置与旧版标记不一致时的中转切换；沿用本篇的工作台和工具管理入口，不改变官方登录条件。
