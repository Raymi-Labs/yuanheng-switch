# Agent Note: Accio 官方更新不再受实测版本白名单限制

Status: implemented

## Problem

官方升级后即使接口仍兼容，用户也会因版本未列入白名单而无法配置或启动。用户明确选择允许尝试新版，实际故障按错误处理，不接受每次等待元衡逐版本放行。

## Decision

移除配置预检、Core启动和状态注解中的版本拒绝，保留官方Bundle ID、Team ID、签名、路径、平台、账号与运行状态校验。前端共用规则只拦截安装不可用，不拦截未实测版本；工作台、工具管理、单项与批量一致。实测版本仅作历史诊断元数据，不能授权或禁止执行，不把未知版伪标为已验证。

取消前端自动查询及仓库定时版本检查；保留按需查询公开版本的工具，不再因未实测版本提示等待升级或将监控判为失败。实际协议错误及诊断保留。本轮不运行官方新包、不发收费模型请求。

## Existing note review

- [兼容预警](../../implemented/feature/2026-10-30-accio-readiness-diagnostics.md)：部分取代版本禁用和定时预警，保留错误分类、查询安全边界与原生验收。
- [0.37.1兼容](../../implemented/bug-fix/2026-10-30-accio-0371-compatibility.md)：部分取代精确版本门禁，保留工具参数适配和历史实测证据。
- 既有商品工作流和干净设备笔记记录历史验收，不能据此声称新版已实测，不重写历史。

## Alternatives considered

- 继续精确白名单：可避免未验收版本进入流程，但所有官方更新都中断用户，与本次要求冲突。
- 仅增加0.37.2或扩大一个版本区间：修改小，但仍在下一次边界升级重现，拒绝。
- 移除版本拦截、保留身份验证：用户可直接尝试官方新版本，兼容故障在实际运行时暴露，采用。

## Verification

前后端无版本拒绝；未知版本在工作台和工具管理可配置/启动/批量选择，未安装及不支持平台仍被阻止；官方查询默认不联网，新版结果不发兼容阻止提示；签名及路径回归保持；相关类型/构建/回归通过，测试遗留进程为零。

最终代码81项前端回归、68项Accio Rust回归及3项版本查询脚本测试通过。前端实际点击覆盖未知版本的单项配置、批量配置及启动，不只是检查按钮样式；未知版本不冒充已实测，安装不可用继续禁用，其他Agent不受此规则影响。签名失败、相对路径、跨账号/分组、撤销与Core身份升级回归通过。版本元数据读取失败时不再将已发现安装标成不可用；身份仍在显式操作时检查。TypeScript、完整前端格式及生产renderer构建通过。

对抗性复核保留失败的真实含义：元数据查询失败不阻止配置；没有显示版本不等于身份通过；没有原生新版模型请求不能宣称协议兼容。旧安装包不因仓库源码改变而自动获得新策略。首次离线Rust检查因缓存已清理缺少依赖，恢复依赖后编译与回归通过；批量测试首次未选中Accio，补上真实选择动作后通过，没有修改产品默认勾选规则。

GUI/Core最终`cargo check --offline --locked --features accio-work-experimental --lib --bins`通过；相关Rust格式检查通过。Bun包装脚本因本机未安装Bun无法运行，使用Node执行同三份笔记校验器通过。未启动官方App、虚拟机或收费模型请求；所有测试/构建命令已退出，收尾无cargo/rustc/vitest/测试二进制/VM测试进程，用户原有GUI/Core保持原状。此记录为本地验证，不代表安装包已更新。

## Consequences

允许尝试不保证官方新协议可用；真实失败仍需诊断修复。历史JSON状态字段保留兼容旧诊断读取，新界面不可据其未实测状态禁用按钮。旧安装包需更新才能获得新行为。
