# Agent Note: 桌面端账号统一令牌与服务端路由

Status: implemented

## Problem

桌面端按设备、分组及创作入口分别查找令牌，跨入口使用会积累凭据。用户明确选择账号统一令牌，接受由平台令牌配置集中决定模型与分组优先级。

## Existing capabilities and impact

复用 device_credentials 的分页、账号校验、进程互斥和持久化未知创建保护，以及 Meta API 已存在的 routing_config 字符串协议。工具配置、凭据修复、Agent 图像和图片视频生成统一进入该入口。平台协议支持 groups 和 model_groups，groups 不含 auto 且最多100项。旧媒体记录按 token_id 查询，保留旧令牌和历史配置，不自动撤销。相关决定见[凭据修复](../../implemented/bug-fix/2026-11-02-credential-group-repair.md)及[创作目录](../../implemented/feature/2026-11-06-media-studio-group-selection.md)。

## Decision

使用固定账号级令牌名，首次创建以所选真实分组优先、其余授权真实组排序填充 routing_config；后续复用同一令牌，保留平台手动编辑的路由、模型限制和额度。持久化账号对应ID以支持重命名，不因停用、过期、额度不足或未知响应再创建。新配置标记平台路由，用量不以目录分组估算费用。分组选择保留为目录筛选；界面明确实际路由由统一令牌决定。

## Alternatives considered

- 继续分组令牌：保持工具独立固定组，但不满足减少令牌的目标。
- 每次切换覆盖统一令牌首选组：改动少，但会影响其他正在运行工具，覆盖用户平台规则。
- 修改服务端支持逐请求强制组：可保留各工具独立组，但涉及第三方工具自定义请求头兼容，用户已接受平台集中路由，无需扩大服务端协议。

## Consequences

2026-11-13用户将修改范围收窄到内置图片Skill，该入口的凭据与“只筛目录”语义由[图片Skill分组修复](../bug-fix/2026-11-13-image-skill-group.md)替代：它按图片组使用独立专用令牌。本文的聊天、创作页、通用功能和平台自动路由决定仍保留，不引入请求级选路协议。

首次使用会新增一枚统一令牌，旧工具在重新应用配置前继续使用旧凭据；图像独立连接需重新连接，通用功能通过凭据修复采用同一令牌。首次授权目录超过100个真实组时拒绝创建，不截断。后续平台新增分组不会自动扩大令牌权限，需要在平台编辑。已有额度限制、模型限制及路由规则不被覆盖；删除令牌后可在平台创建同名多分组令牌再采用。

本机持久化ID支持重命名；另一台尚未使用过该令牌的设备依靠固定名称发现，因此跨设备首次接入前应保留固定名称。多个设备同时首次创建仍缺少服务端幂等键，不保证跨进程/跨设备原子唯一；同名重复时提示处理，不继续新增。旧凭据不删除，历史视频保留原ID。用户接受由平台令牌集中路由，目录选择不再承诺固定分组计费。
