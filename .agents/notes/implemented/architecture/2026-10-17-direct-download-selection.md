# Agent Note: 新入口参与更新下载择优

Status: implemented

## Problem

meta-api.vip 的新入口整包实测快于 R2，但当前下载器仅比较 R2/GitHub，原平台 URL 仍临时跳转 R2，无法利用新线路。

## Decision

复用现有并发小块探测、低速切源、Range 续传和完整签名校验，将精确官方更新包候选扩展为 meta-api.vip?origin=1、R2、GitHub。直接复用线上已有 origin=1 只读旁路，不修改 Nginx、系统代理或 API 路由。旧裸镜像 URL 仍能识别；未知参数、域名和版本保持原 Tauri 行为。

## Existing decisions

检索 active notes：与 [R2 分发](2026-10-13-r2-desktop-delivery.md) 部分重叠，本篇取代其客户端仅 R2/GitHub 的决定，保留 R2 优先同步、旧链接跳转和发布校验；与 [下载故障恢复](../bug-fix/2026-10-12-update-download-failover.md) 部分重叠，复用恢复与签名边界。API 线路自动选择独立，不扩大到模型请求。

## Alternatives considered

- 只固定新直链：当前样本快，但不能覆盖地区和时段差异；保留三源竞争和失败恢复。
- 移除全站安装包 R2 跳转：能惠及旧客户端，但需要新的生产配置变更，且改变已运行的旧链接行为；已有显式直链满足本次新客户端和官网需求。
- 重写多线程下载器：复杂度和额外流量更大；现有有界下载器已支持任意候选数。

## Verification

11 项 Rust 下载回归通过：三平台精确映射和拒绝未知参数；第三源首块最快；首源断开、第二源 503 时第三源从已下载偏移续传；错误范围、编码、大小、签名和整体超时。三源测试发现旧实现对 503 清空前缀，本次只在错误范围/内容及 416 时重置，其他不可用 HTTP 响应保留前缀。

版本检查、TypeScript、146 文件 931 项前端测试和 renderer 构建通过。当地 Node 25 的实验 Web Storage 导致 5 项旧测试误失败，沿用 NODE_OPTIONS=--no-experimental-webstorage 后全通过，不改业务代码。正式 UA 原生单源 smoke 在当前系统代理获取清单时连接超时，尚未到安装包步骤；直连和发布验收单独记录，不声称代理路径通过。


## Consequences

短首块择优不保证整个文件持续最快，已有低速切换处理后续变化。新入口仍受服务器带宽和用户代理影响，不能承诺所有用户固定速度。首次升级到本版仍使用旧客户端下载器，三源从本版后续更新开始生效。
