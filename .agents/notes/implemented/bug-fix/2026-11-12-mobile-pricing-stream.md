# Agent Note: 移动端大型定价目录读取

Status: implemented

## Problem

移动端pricing与其他接口共用4MiB整包JSON读取，模型说明和FAQ增长会让目录不可用。外部交付包提供流式丢弃无用字段及24张卡片分批显示的实现；不能把其APK、测试记录或版本号当成本仓库发布结果。

## Decision

仅在mobile_api的pricing分支复用专用流式解析器，保留完整模型集合及前端Pricing类型使用的字段；其他操作的4MiB限制、固定域名、登录凭据和epoch检查不变。网络总量上限64MiB，压缩后目录预算8MiB，有界分块通道和阻塞解析任务，继承45秒请求超时。增强交付代码：保留值逐节点计预算、节点/深度限制、重复字段拒绝和可重复的字段契约测试，避免先构造整个超大保留值再检查大小。

模型页在全量目录上搜索、筛选、排序后每次显示24张卡片，改变筛选和数据后重置。只增加加载按钮，不复制生成Android工程或图标。用户后续授权合并发布，Android使用alpha.6/versionCode6，避开既有已撤回alpha.5与同名伙伴交付包；包名和正式签名不变。

## Existing decisions

[移动端架构](../../implemented/architecture/2026-10-19-mobile-clients.md)与[外部媒体整合](../../implemented/feature/2026-11-07-mobile-external-media.md)部分重叠，继续沿用账号隔离、原生网络与媒体边界；本次仅扩展pricing读取与列表呈现。无替代整套移动架构或新增独立请求通道。

## Alternatives considered

- 直接将整包限制提高到8MiB：改动最小，但无用元数据继续占内存，未来仍可能越限。
- 服务端分页：能减少下载量，但需跨项目API契约及部署，本轮本地客户端整合不包含该范围。
- 受限流式解析：保持现有接口，额外维护字段白名单与预算，但可跳过无用字段并保留完整搜索能力。

## Verification

49项前端、28项Rust测试通过，类型、renderer构建、Clippy all-targets -D warnings通过。9MiB无用元数据解析通过，5MiB本地HTTP响应保留末尾模型及价格；旧4MiB读取路径拒绝同一响应。测试覆盖完整前端字段契约、序列化预算、重复字段、深嵌套、节点过多、截断、鉴权拒绝、无Content-Length超限和超时；关闭生产端后解析任务正常结束。

生产dist的独立Chromium合成IPC回归验证236个模型先显示24项、展开48项、搜索末尾模型并打开详情、清空搜索重置，以及320/390px无横向溢出。渲染截图检查通过，外部请求0；不是手机触摸/原生安装包或线上目录实测。未读取真实账号数据或调用模型。测试使用单任务Rust编译并关闭增量缓存，结束清理临时构建和浏览器进程。

## Consequences

避免因无用元数据增长直接触发原4MiB限制，并减少首屏DOM数量。代价是仍下载完整响应并维护字段白名单，新增前端Pricing字段由测试提示同步；不是网络分页。8MiB是保留数据预算而非整个进程峰值内存，serde解码单个字符串的临时缓冲仍受64MiB网络限制。真实手机安装、触摸及线上接口仍需后续验收，签名交付不等同真机行为通过。
