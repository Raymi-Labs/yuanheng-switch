# Agent Note: 独立图像分组与真实可用状态

Status: implemented

## Problem

多应用技能使用当前聊天连接的凭据。用户在另一台电脑使用 DSH 的福利分组与 gpt-6-astra，技能已经执行，却在模型选择阶段提示没有带版本号的 GPT Image。公开平台目录中的 GPT Image 仅列于 OpenAI 分组；本机另一套聊天分组的真实凭据目录也只有 Qwen 图像模型。聊天能够调用与 GPT Image 权限是两个条件，固定模型名不能赋予权限。

现有图像状态只核对技能、连接与本地 Core，未核对真实令牌模型目录，可能显示已就绪。JS helper 不接受命名空间前缀，但 Rust 目录允许此前缀，另有跨层格式不一致。

## Decision

复用现有账号分组、设备令牌获取、凭据保护和每工具图片路由，增加用户明确选择的独立图像分组；仅改变图片路由，保留聊天模型与分组。不根据公共价目表猜测权限，不自动切换到不同计费分组。未选择独立分组时兼容现有工具连接。

图像连接绑定当前账号与技能目标，登录变化和关闭状态不能让旧凭据继续调用。状态通过有界只读目录请求展示可用 GPT Image 和最新质量优先型号；配置时校验实际令牌权限。UI 提供明确分组选择与恢复使用聊天连接的入口，技能与导入包不携带 API Key。

桌面进程把独立图片凭据保存在系统凭据库，Core 通过既有管理 Bearer 认证的本机通道接收只驻内存的副本；不依赖不同可执行文件共享 macOS Keychain ACL，也不把凭据写进 SQLite、runtime 或临时文件。Core 每次按当前分组绑定、账号代次和技能启用状态核验，旧快照不能恢复已撤销凭据。启动、重启和维护周期补齐 Core 内存，凭据同步失败只影响独立图片能力；状态走实际 Core 的只读模型目录才认定就绪。

模型识别支持命名空间前缀，比较尾部数字版本与质量，发请求时保留原始完整模型 ID。没有可选型号时说明分组授权条件，不建议以显式名称绕过权限。保留 POST 单次执行及 Codex 原生路径保护。

## Existing decisions

[多应用图像技能](../feature/2026-10-23-multi-app-image-skill.md) 部分重叠：保留投影、绑定、每目标启停、宿主限制和本机 ZIP；本篇替代图像只能使用聊天分组的限制。[自动图像技能](../feature/2026-10-23-automatic-image-skill.md) 部分重叠：保留真实目录、版本排序、质量优先和请求不重复的决定。检索其余 active notes 未发现独立图像分组决定。

## Alternatives considered

- 让用户将 DSH 聊天分组改成 OpenAI：可立即复用原连接，但破坏原聊天分组与模型选择，且未来其他聊天提供方仍会遇到相同问题。
- 错误时硬编码最新型号或改用公共目录：实现简单，但不能证明令牌有权限，也无法解决分组限制。
- 自动借用 Codex 或其他应用的 Key：可能恰好有权限，但隐式改变账号或计费来源；采用当前账号明确选择的图像分组。
- 由 Core 直接读桌面写入的 Keychain：少一次本机传递，但不同可执行程序的读取权限无法从桌面写入校验推导；使用既有受控管理通道，不扩大 Keychain ACL。
- 只改善错误文字：能解释失败，仍无法同时使用福利聊天与 GPT Image；同时修复连接能力与诊断。

## Verification

- Rust 全量 2472 项单元测试及 116 项集成测试通过，3 项既有忽略项。独立连接、Core 内存同步、真实本地 HTTP、旧多应用生命周期及账号并发回归均包含在完整测试中。
- helper 145 项测试通过，包括命名空间完整 ID、数值版本与质量排序、专用路由强制 Images API、旧描述兼容及不重复生成；技能结构校验通过。
- 前端 153 文件 1023 项测试、typecheck、renderer build 和格式检查通过。完整 App 模拟 IPC 验证 DSH 只改变图片连接、最新型号展示、目录失败与关闭清除就绪、恢复聊天连接、刷新持久化；1440×900 明色、800×650 暗色目视检查无横向溢出，console 无应用错误。
- Clippy `-D warnings`、Rust 格式、diff、版本一致性及 43 篇笔记校验通过。测试中的外部请求使用本地模拟服务，没有真实付费图像调用，也没有修改本机或远端 DSH 的聊天配置。

## Consequences

真实目录只证明可见模型，不保证上游生成成功。客户端关闭期间若 Core 重启，独立图像连接需要重新打开客户端恢复内存凭据；不通过磁盘明文、跨程序 Keychain ACL 或借其他应用 Key 消除这个限制。独立图片分组要求可持久登录；仅内存会话不能让重启后的独立 Core 识别其失效，保留既有聊天连接行为并明确提示保存登录，不新增会话租约。另一台电脑不能在本机直接验收；新版本需要在那台电脑升级并选择有权限的图像分组。本轮不以付费生图测试替代用户授权。
