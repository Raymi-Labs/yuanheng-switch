# Agent Note: Codex 本机代理绕过与登录环境兼容

Status: implemented

## Problem

系统 HTTP 代理缺少本机绕过时，Codex 请求可能未到达 Core 即失败。管理请求的 no_proxy 不能保护外部进程；网页 200 和重连次数均不是推理成功证据。

## Decision

复用 misc 桌面/终端启动、App Server 子进程及智能体检。两种大小写绕过列表取并集并加入 localhost/127.0.0.1/::1，不修改公网代理。macOS open 使用明确的 --env；运行中实例提示重启。终端脚本还合并实际终端环境，用户内容不作为 shell 代码执行。Windows 普通子进程注入环境；Store 启动与其他平台手动启动保持未验证边界。

托管 Codex 路由存在时，体检对无凭据 /health 使用直连与系统默认代理路径，限制时间、正文和重定向，检查 Core 身份；直连失败不判定代理问题。Core 到上游复用现有选路器 15 分钟内的无计费检查证据，过期明确待检查，不将 GUI 账号 API 当作 Core 出站成功。默认代理探针属于元衡当前环境，不冒充客户端自有代理配置；结合实际进程与客户端日志诊断。

独立显式启用可撤销用户 LaunchAgent，覆盖后续 Dock/Finder 启动。登录脚本保留原环境快照、合并原有及新条目、重复运行不覆盖恢复记录、部分失败回滚；撤销比较当前值与已应用值，外部修改不覆盖。仅管理自己的标签与文件，不接管用户手工修复。配置目录 0700，脚本 umask 077，符号链接冲突拒绝，删除不递归清理用户新增内容。空环境变量撤销为 unset，含义均为无绕过条目。

macOS 通过 KERN_PROCARGS2 核对实际环境，只返回进程数和保护布尔值，不记录原始命令或环境。SIP 隐藏的环境属于未确认。受控重启只终止当前用户所选包的主进程和模型后端，等待退出，不按全局同名进程强杀；路径先规范化，兼容 /var 到 /private/var 的符号链接。

## Existing note review

[出站连接池](2026-10-12-outbound-connection-stability.md)部分重叠，保留出站策略；[配置验收](../feature/2026-10-31-tool-configuration-checks.md)部分重叠，沿用配置不等于调用成功。其他匹配的 Accio/TRAE/安装笔记不负责本机 Codex 环境，无迁移或归档。

## Alternatives considered

仅在启动按钮设置变量最简单，但无法覆盖 Dock 和已有实例；因此增加显式登录修复与进程复验。修改系统代理排除列表会影响第三方软件规则并可能被覆盖，不采用。自动关闭 VPN、重试收费请求或放宽超时不能修复本段链路，不采用。单看 open 返回 0 不能证明继承，必须检查主进程与已出现的模型后端；后端尚未创建则明确不能确认。

## Verification

本机模拟代理回归证明不绕过时本机探针进入代理，合并后不进入代理，公网测试地址仍经过代理。真实 Codex 二进制对照：缺少绕过时失败，3 次本机请求进入模拟代理；仅增加两个绕过变量后完整返回 OK、turn.completed，代理命中 0。另一次保留系统 Shadowrocket 开启、原模型配置的真实流式调用也完成 OK。

原生 LaunchServices 合成应用验收通过显式 --env 启动、普通 GUI 启动继承、实际进程检查、受控退出、用户 LaunchAgent 应用/撤销及原值恢复；没有重启用户真实 Codex。隔离登录脚本 6 项通过，覆盖原值、大小写、重复执行、重新登录新条目、冲突、写入/恢复部分失败及特殊字符；纳入 CI。4 项 Rust 代理测试通过，另有显式原生 QA 与子进程 fixture 默认忽略。前端新增 4 项显式操作边界测试通过；全量 1315 项通过。本机 Node 25 原生 localStorage 干扰旧测试，使用 NODE_OPTIONS=--no-experimental-webstorage 后通过，与 CI Node 20 行为一致，不改业务代码绕过断言。

Rust 全量 2706 项单元与 116 项集成测试通过（10 项既有/夹具忽略）；最终代理定向测试、Clippy、类型、格式、renderer/Core 构建、版本与笔记检查通过。发布与三平台安装包结果以 GitHub 工作流为准。

## Consequences

环境设置、实际继承和真实流式完成分开显示，避免把所有重连归因为代理。登录修复作用于当前用户后续启动且支持变量的应用，已有实例不能原地注入；默认不改系统代理、不触发模型调用或上传诊断。应用退出需用户确认并保存任务；不能读取内核环境或未出现模型后端时保持未确认。

真实目标 Mac mini 的 Dock 点击、注销再登录及升级安装包验收没有在本轮执行；普通 LaunchServices 与脚本重放覆盖其机制，但不冒充这些人工场景。Windows Store 手动启动和 Windows/Linux 真机环境未验证。登录修复与手工 LaunchAgent 同时存在时可能互相覆盖，体检/撤销冲突会提示，不能静默删除外部修复。外部环境发生冲突需用户处理；保留配置优先于强行撤销。
