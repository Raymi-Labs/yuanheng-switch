# Agent Note: 桌面应用下载等待的退出与刷新语义

Status: implemented

## Problem

外部浏览器关闭不通知客户端，等待安装实为本机检测而非下载进度。重新检测未停止旧监测，openExternal 异常在 finally 外会遗留转圈，旧探测晚返回可触发配置。

## Decision

复用 useDesktopInstallFlow：每次监测持有独立 AbortController；重新检测停止所有旧监测，卸载也清理等待。打开网页纳入清理范围，等待设整体五分钟上限，检查停止信号后才接受探测结果。停止仅结束观察，不声称取消浏览器下载或后端检测进程。保留手动路径入口。

## Alternatives considered

- 监听外部浏览器关闭：客户端不拥有浏览器，无法可靠获知关闭事件，不猜测。
- 只刷新版本数据：不解除旧监测和其异步副作用，不能解决转圈。
- 停止时结束检测进程：本轮不改变共享只读探测的进程所有权，不能误杀其他检测。

## Verification

新增 5 个 hook 回归：打开失败清理、重新检测停止并忽略迟到结果、打开请求悬挂时整体超时、重启监测时旧 finally 不清新监测、正常检测和卸载清理定时器。前端全量 836 项、TypeScript 通过；没有真实打开下载页或安装工具。本轮继续仅本地，不推送。

## Consequences

单个底层只读 IPC 可能继续执行，本改动仅使观察者有界且忽略迟到结果；不代替后端探测有界化。浏览器下载状态未知，关闭浏览器本身不自动停止浏览器下载，但元衡不再无限等待。重新检测会结束旧观察并立即建立新检测；其代价是用户必须再次触发检测，不会自动猜测网页安装结果。
