# Agent Note: 原生工具安装的超时与安全取消

Status: implemented

## Problem

安装执行使用无限等待的 output()，无超时或取消，输出全量缓存在内存中。前端锁覆盖验证阶段，但无法阻止挂起安装长期占用。取消不能只是界面状态变化，必须停止本任务拥有的进程后才允许重试。

## Decision

扩展既有安装 IPC、跨入口状态与后端锁，为原生 CLI 安装提供唯一 operation ID、10 分钟执行上限、stdout/stderr 各最多 64 KiB 尾部输出、真正取消。Unix 使用独立进程组，Windows 使用 kill-on-close Job Object，并在任务进入 Job 前用 stdin 门闩阻止批处理启动安装器。进程退出成功后也回收组内残留子进程；操作 ID 防止迟到的取消影响下一次安装。取消/超时不代表文件回滚，不自动重装，先重新检测。验证阶段保持现有只读检测，不把“停止验证界面”伪装成取消安装。

工具页、快捷控制台和关于页共用取消控件，显示取消中直到后端确认；失败可再次尝试，不清除仍在运行的任务状态。一次批量升级的停止语义不在本轮扩大，更新仍沿用既有行为。WSL 安装明确不提供原生进程树取消/超时承诺，绝不终止整个发行版；查询执行策略后才显示取消按钮。

[DSH 独立安装](2026-10-11-dsh-install-launch.md)复用本监督器，将临时目录与发布标记纳入自身事务；只有该任务验证完成才选择托管运行时，不扩大其他工具的安装能力。

## Existing notes audit

[安装与模型选择连续性](2026-10-01-tool-install-and-model-picker.md) 拥有任务状态与互斥。本笔记补齐其明确保留的超时/取消缺口，不推翻模型缓存与账号隔离决定。其余诊断笔记不涉及安装进程所有权。

## Alternatives considered

- 前端 Promise.race 超时最简单，但后台继续写文件，释放锁会允许重叠安装；不采用。
- Windows taskkill /T 易集成，但父进程提前退出后无法可靠定位剩余树；采用 Job Object，先入 Job 后放行脚本，避免绑定竞态。
- 自动重试或全局杀同名进程可快速恢复表面状态，但可能重复安装或误伤用户已有终端；仅终止本任务进程组/Job，用户明确重试。

## Verification

- 无真实软件安装的子进程回归覆盖成功、失败、取消、超时、父进程成功退出后残留子进程、输出洪泛、启动失败、操作 ID 隔离。补充独立进程不受取消影响，输出读取任务的 RAII 保证异常退出也不留下后台 reader。
- Linux、macOS、Windows CI 的 Rust 编译、Clippy 与真实子进程测试通过。Windows Job 实测，不以字符串断言替代；关闭 Job 并确认 ActiveProcesses 为零后才完成。Unix 停止任务组并等待直接子进程结束，已停止的组不再次按旧 PID 发送信号。
- 前端全量测试、TypeScript、格式与 renderer 构建通过；新增跨入口取消、后端拒绝恢复、迟到响应不影响重试、取消之后不再验证或报成功用例。
- 独立 Chrome 使用模拟 Tauri IPC：两处按钮同步取消中、停止前安装按钮禁用、后端结束才回到 idle、明确重试成功、WSL 不展示取消按钮。浏览器、Vite 与测试进程均已结束，不代替干净 Windows 真机下载验收。
- 版本保持 0.1.63、不打发布标签，不增加收费请求或原始日志上传；最终改动仍须通过 PR 三平台 CI 才合并 main。

## Consequences

原生安装不再无限占用输出内存或无限执行，取消按实际进程所有权收敛；代价是超过十分钟的慢速下载也会停止，部分安装文件须用户重新检测处理。清理失败保留后端工具锁，宁可提示重启检查也不允许未知写入者与新安装重叠。后台任务到验证阶段才释放取消能力，验证完成前仍保持原来的互斥状态。

Unix 恶意主动 setsid 脱离任务组不在可信官方安装器约束内；Windows Job 绑定失败时拒绝启动安装脚本。取消不能回滚第三方已写文件，提示重新检测。WSL、升级与整段版本验证的有界化保留为独立工作，不声称干净 Windows 真机安装已经验收。环境支持查询只判断能否安全监督本次安装，并非网络、权限或依赖的全面通过证明。
