# Agent Note: Accio 官方只读目录与连接状态使用独立白名单

Status: proposed

## Problem

主模型接入不能替代 Agent 的业务能力。当前网关连官方插件目录和已有连接授权状态也拒绝，用户无法正常发现可用功能。原版 0.35.3 gateway-worker（SHA256 8effbddb576d5ae6feea2a8512e33f6d0c8700e707221db1f4027d2e9475ea9f）确认插件 list/detail 使用 GET，连接 query/authorization/status 使用 POST；这些均是读取操作。

## Proposal

复用受控 Core、当前启动能力令牌和不重试的 HTTP 客户端，单独允许四个精确官方端点。请求重建仅含已确认的查询字段/官方 accessToken，拒绝重复、未知字段和超限请求；不转发元衡凭据、Cookie、设备标识或本地 URL。响应有界读取并验证 JSON，保留官方非成功状态，不伪造空目录/空授权成功。连接器错误仍有五秒节流，独立并发额度，不挤占模型请求。

官方域名固定，不允许重定向。插件安装/下载票据、账号授权/解绑、mcp/proxy 执行以及未知端点保持拒绝。此改动只补充发现与状态查询，不据此宣称云端业务工具已可执行。文案明确区分元衡推理与官方账号服务。

## Existing note review

- [干净设备验收](../../proposed/testing/2026-10-19-accio-clean-macos-vm.md)部分重叠：保留此前501与原生文件任务失败记录，本篇另记新结果。
- [受控桌面入口](../../implemented/feature/2026-10-21-accio-verified-desktop-entry.md)部分重叠：复用签名/版本/活进程鉴权，不放宽安装来源。
- [流错误诊断](../../implemented/bug-fix/2026-10-21-accio-stream-error-diagnostics.md)不替代：仍负责推理流错误，不读取云端响应正文进日志。

## Alternatives considered

- 保持全拒绝：边界简单，但连必要的只读发现也不可用，不能满足完整 Agent 体验。
- 所有未知端点转发官方：兼容范围大，但包含推理、云端写操作与上传，无法区分凭据去向和用户操作范围。
- 精确四端点只读白名单：维护成本更高，不能保证后续版本兼容；能恢复已核实的发现入口，同时限制外部副作用。

## Acceptance criteria

四端点的正确方法与字段通过；变体路径、重复/未知字段、凭据混用、重定向、非JSON/超限/超时/取消均不泄漏凭据。调用失败有明确错误而非空成功；连接器失败节流不持有模型并发槽位。实际生成测试仅使用 Astra 和用户批准分组，文件验收须有原生执行与磁盘结果，两者独立于目录接口测试。结束无测试遗留进程。

## Risks

官方目录/授权返回可能含账号信息，仅返回原版应用，不记录正文或提交仓库。四端点尚需原版联网验证，单测通过不代表官方业务流程通过。只读目录可能包含安装入口，但本轮不增加自动安装权限。默认实验开关和发布保护保持。

## Local validation

当前代码和前端告知已落盘；通过固定0.35.3哈希提取官方只读方法，在无网络合成环境中核对4条真实方法/字段契约。Rust覆盖字段/路径/凭据/授权撤销/错误响应/重定向/大小边界，前端相关11项和类型检查通过。新版Core曾在VM安装、受控启动成功，但系统局域网权限提示未授权，尚未完成原生业务验收，因此保留proposed，不作为发布凭据。

用户指定后所有真实模型请求仅为鹈鹕王gpt-6-astra：原生文件任务502、未写入；最小write协议完整返回4191/49 tokens和合法工具参数，检查器未执行工具。不能以协议通过替代文件落盘。原Core恢复、合成input/guard未改，收尾正常关闭VM；具体结果见[干净设备报告](../../../../docs/reviews/2026-10-19-accio-clean-macos-vm.md)。
